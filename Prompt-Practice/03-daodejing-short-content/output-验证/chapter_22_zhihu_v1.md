# 第 22 章：曲则全——理解“以退为进”的底层逻辑
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
曲则全，枉则直；洼则盈，弊则新；少则得，多则惑。
是以圣人抱一为天下式。
不自见，故明；不自是，故彰；不自伐，故有功；不自矜，故长。
夫唯不争，故天下莫能与之争。
```

## 解释
**曲则全，枉则直；洼则盈，弊则新。**
委屈反而能保全，弯曲反而能伸直；低洼才能被填满，陈旧才能换新。

**少则得，多则惑。**
目标少反而能获得，贪多反而会陷入迷惑。

**不自见，故明……夫唯不争，故天下莫能与之争。**
不自我表现反而更显眼，不自以为是反而更出名。不夸耀功劳，不自满自大。正因为不与人争，天下才没有人能争得过你。

## 分析
老子揭示了一个反直觉的真理：事物的本质往往隐藏在对立面中。所谓的“曲则全”，不是教人软弱，而是强调在复杂系统中的柔性生存策略。在坚硬的规则面前，懂得适度弯曲的人更有生命力。

“少则得”是现代极简主义的先驱。在信息爆炸的时代，我们的“迷惑”大多源于对“多”的执着。只有懂得“抱一”（专注核心），才能从纷杂的欲望中解脱，找到最高效的路径。

“不争之争”是最高级的博弈。当一个人不再为了证明自己而内耗，所有的能量都会转化为实实在在的成长。这种基于实力的低调，反而会形成一种降维打击，让竞争对手无处发力。
