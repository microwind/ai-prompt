# 第 22 章：曲则全，委屈方能保全
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
曲则全，枉（wǎng）则直；洼则盈，弊（bì）则新；少则得，多则惑。
是以圣人抱一为天下式。
不自见（xiàn），故明；不自是，故彰；不自伐，故有功；不自矜（jīn），故长。
夫唯不争，故天下莫能与之争。
古之所谓“曲则全”者，岂虚言哉？诚全而归之。
```

## 解释
**曲则全，枉则直；洼则盈，弊则新；少则得，多则惑。**
委屈反而能保全，弯曲反而能伸直；低洼才能被填满，陈旧才能焕然一新；目标少反而能获得，贪多反而会陷入迷惑。

**不自见，故明；不自是，故彰；不自伐，故有功；不自矜，故长。**
不自我表现反而更显眼，不自以为是反而更出名。不夸耀功劳反而有功绩，不自满自大反而能长久。

**夫唯不争，故天下莫能与之争。**
正因为不与人争，天下才没有人能争得过你。古人说“委屈保全”怎么会是空话呢？它是实实在在可以达到的。

## 分析
老子揭示了一个反直觉的真理：事物的本质往往隐藏在对立面中。所谓的“曲则全”，不是教人软弱，而是强调在复杂系统中的柔性生存策略。懂得适度弯曲，往往比生硬对抗更有生命力。

“少则得”是认知的精进。在信息过载的时代，迷惑大多源于对“多”的执着。只有懂得“抱一”，专注于核心价值，才能从纷杂的欲望中解脱。

真正的强大源于内敛。当一个人不再为了证明自己而内耗，所有的能量都会转化为实实在在的成长。这种“不争之争”，才是最高级的竞争策略。
