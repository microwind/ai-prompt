# 第 64 章：为什么很多人总是“差一点就成功”？
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
其安易持，其未兆易谋……
合抱之木，生于毫末；九层之台，起于垒土；千里之行，始于足下。
为者败之，执者失之。
民之从事，常于几成而败之。慎终如始，则无败事。
```

## 解释
**为之于未有，治之于未乱。**
处理事情要趁它还没发生时就开始；治理祸乱要在它还没抬头时就动手。

**合抱之木，生于毫末……千里之行，始于足下。**
参天大树是从嫩芽长起的，九层高台是从泥土堆起的，千里的路程是从第一步走起的。

**慎终如始，则无败事。**
人们做事常在快成功时失败。如果能像开始时那样谨慎对待结尾，就不会有办不成的事。

## 分析
成功没有捷径，只有“治未病”和“拼积累”。很多麻烦如果能在刚露头时解决，成本是最低的。别等火烧眉毛再找水，要学会在风平浪静时修堤。

老子告诉我们，任何宏大的事业都是由微小的动作累加而成的。与其每天焦虑未来的结果，不如低头走好当下的每一步。这种“始于足下”的踏实，是对抗焦虑最好的良药。

最扎心的一句话是“常于几成而败之”。很多人输在了最后那1%的松懈上。所谓高手，就是那个在大家都想庆祝胜利时，依然能保持初心、如履薄冰的人。慎终如始，才是成事的终极算法。
