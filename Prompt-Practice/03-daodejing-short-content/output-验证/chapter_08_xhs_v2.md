# 第 8 章：上善若水，最高级的格局是不争
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
上善若水。水善利万物而不争，处众人之所恶（wù），故几（jī）于道。
居善地，心善渊，与善仁，言善信，政善治，事善能，动善时。
夫唯不争，故无尤（yóu）。
```

## 解释
**上善若水。水善利万物而不争，处众人之所恶，故几于道。**
最好的善行就像水一样。水滋润万物却不与万物争抢，它愿意停留在众人厌恶的低洼潮湿之处，所以这种品性最接近于“道”。

**居善地，心善渊，与善仁，言善信，政善治，事善能，动善时。**
有道的人：居住选择清静之地，心胸如深渊般沉静，待人真诚无私，言语守信一致，治理政务井然有序，办事发挥才干，行动把握时机。

**夫唯不争，故无尤。**
正因为能做到与世无争，所以才不会招致怨恨，也就没有过失和烦恼。

## 分析
真正厉害的人，往往像水一样“利他”。在职场或生活中，水滴石穿靠的不是硬碰硬，而是顺应环境的韧性。懂得向下扎根，才能向上生长。🌱

我们要学习水的格局：在别人看不上的“低洼”机会里默默蓄力。心境要像深渊一样稳，外界再嘈杂，内心也要有自己的秩序感。💡

行动要讲究“时机”。不争不是不作为，而是不在无意义的事上内耗。当机会来临时，果断出击；平时则像溪水，绕过障碍，奔向目标。🌊
