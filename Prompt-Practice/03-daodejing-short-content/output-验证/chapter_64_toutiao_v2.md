# 第 64 章：慎终如始，则无败事
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
其安易持，其未兆（zhào）易谋；其脆易泮（pàn），其微易散。为之于未有，治之于未乱。
合抱之木，生于毫末；九层之台，起于垒（lěi）土；千里之行，始于足下。
为者败之，执者失之。是以圣人无为故无败，无执故无失。
民之从事，常于几（jī）成而败之。慎终如始，则无败事。
是以圣人欲不欲，不贵难得之货；学不学，复众人之所过。以辅万物之自然而不敢为。
```

## 解释
**为之于未有，治之于未乱。**
做事情要在它还没发生前就准备好；治理祸乱要在它还没抬头时就动手。就像中医讲“治未病”，等病入膏肓再求医，往往为时已晚。

**合抱之木，生于毫末；九层之台，起于垒土；千里之行，始于足下。**
参天大树是从细嫩的小芽长成的；九层高台是从一筐筐泥土垒起的；千里的远行是从脚下的第一步开始的。任何宏大的事业，都离不开点滴的积累。

**慎终如始，则无败事。**
人们做事，往往在快要成功时却失败了（功亏一篑）。如果能像刚开始时那样充满激情、谨慎对待结尾，就没有办不成的事。

## 分析
老子揭示了一个扎心的真相：大多数人的失败不是因为没能力，而是因为“最后1%的松懈”。我们在刚开始做一件事时往往如履薄冰，但越接近终点，就越容易产生“差不多了”的傲慢。高手与普通人的区别，就在于那份“慎终如始”的定力。

事业的成败，藏在“未兆”之中。真正聪明的人，懂得在风平浪静时修堤，而不是在洪水来临时求神。凡事提前布局，解决问题在萌芽状态，这才是成本最低、效率最高的生存智慧。

不要被宏大的目标吓到。合抱之木始于毫末，只要方向正确，剩下的交给时间。对抗焦虑最好的方式，不是展望未来，而是“始于足下”的踏实。哪怕每天只挪一小步，只要不停步，就能到达千里之外。
