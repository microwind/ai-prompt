# 需求分析文档：道德经简版改编项目

## 1. 目标受众分析 (Target Audience)
- **核心画像：** 25-45岁，职场人、创业者、生活节奏快的现代人。
- **痛点：** 传统经典深奥难懂，缺乏与现实生活的直接映射。
- **阅读场景：** 碎片化阅读（通勤中、午休、睡前），期望在短时间内获得心灵启发或实用的世俗建议。

## 2. 各平台特点与适配策略
| 平台 | 特点 | 适配建议 |
| :--- | :--- | :--- |
| **小红书** | 视觉驱动、情绪导向 | **必加 Emoji**、强调情感共鸣、标题需吸睛。 |
| **微头条** | 快速阅读、大众化、高互动 | 语言极其直白、多用反问句、关联大众共识。 |
| **知乎** | 专业严密、求真务实 | 逻辑清晰、强调哲学背后的“第一性原理”。 |
| **公众号** | 沉浸感、品牌价值 | 排版整齐、全文保留范本格式、文末引导关注。 |

## 3. 核心内容规范 (Core Standards)
- **文字风格：** 核心特征为“简”、“朴”、“悟”。
- **长度限制：** 严禁冗长，控制在《第一章范本》的 **110%** 以内。
- **标题规范：** 统一使用 `# 第 X 章：[章节标题或金句]`。
- **结构化组件：**
  - `## 原文`：代码块呈现。
  - `## 解释`：加粗原文，并紧跟白话，减少繁文缛节。
  - `## 分析`：重点在于将老子思想转化为现代人的可落地启发。
  - `## 链接`：统一使用底部的标准资源库链接。

## 4. 排版与 Emoji 规范
- **小红书/微头条：** 在重点段落末尾添加相关 Emoji（如：📜, 🌱, 💡, 🚪）。
- **标点符号：** 全文使用标准中文标点，避免滥用感叹号。
- **分段：** 单个段落建议不超过 3 行，方便手机端滑屏。
