# 🏗️ 《理解道德经》短内容改写内容设计提示词

> 用于让模型根据需求分析文档产出一份完整的内容生产设计方案

---

## 📌 适用场景

当你已经完成需求分析，希望 AI 继续输出单章改写结构、平台模板、输出规范、质量标准和批量处理规则时，可以使用本提示词。

---

## 🎯 Prompt 目标

让模型输出：

- 单章改写方法
- 平台模板设计
- 输出结构建议
- 风格与篇幅规范
- 质量校验标准
- 批量处理规则

---

## ✅ 完整 Prompt 模板

```markdown
你是一位资深内容总编，同时熟悉经典文本改写、现代汉语表达、多平台内容分发和批量内容生产规范。

现在我准备把《理解道德经》按章节改写成适合小红书、微头条、知乎发布的简洁版本。下面我会提供需求分析结果，请你基于这些内容输出一份完整的内容设计方案。

【输入材料】
以下是已经确认的需求分析文档：

{在这里粘贴需求分析结果}

【你的任务】
请基于需求文档，设计一套可落地、可批量执行、风格统一的内容生产方案。重点关注如何从每章原稿中提炼主题、压缩表达、保留原意，并适配不同平台的阅读习惯。

【设计要求】
1. 设计单章处理流程：阅读原稿、提炼主题、抽取关键句、生成简洁版、平台适配
2. 设计统一的单章输出结构
3. 针对小红书、微头条、知乎分别给出模板建议
4. 说明是否保留原文引句、如何保留、保留多少
5. 给出“忠于原意”与“现代化表达”的平衡规则
6. 给出“简洁但不空洞”的处理原则
7. 设计质量校验标准，防止：
   - 偏离原意
   - 语言过度鸡汤化
   - 平台语气失真
   - 各章风格不统一
8. 设计批量处理规范，方便后续 81 章连续生产
9. 如果需要，给出单章输出字段建议，方便后续生成 skill

【特别约束】
1. 必须以原稿为核心输入
2. 输出定位是“简洁版理解与表达”
3. 不要把内容写成学术论文
4. 不要把内容写成网络情绪文案
5. 不要为追求传播而牺牲原文核心含义
6. 方案要足够结构化，方便后续继续生成批量生产 Prompt 或 skill

【输出格式】
请严格按以下结构输出：

# 内容设计方案

## 1. 设计目标与原则

## 2. 单章处理流程
- 原稿阅读
- 主题提炼
- 关键句抽取
- 简洁版生成
- 平台适配

## 3. 单章输出结构建议
- 标题
- 原文引句
- 简洁版正文
- 一句话总结
- 可选扩展说明

## 4. 平台模板建议
### 4.1 小红书模板
### 4.2 微头条模板
### 4.3 知乎模板

## 5. 风格与篇幅规范
- 语言风格
- 字数建议
- 句式建议
- 节奏建议

## 6. 忠于原意的控制规则

## 7. 质量校验标准
- 内容准确性
- 可读性
- 平台适配性
- 风格统一性

## 8. 批量生产规范
- 命名规范
- 输入规范
- 输出规范
- 复核规范

## 9. 可用于 skill 的结构化字段建议

## 10. 风险点与备选方案

请使用专业、清晰、可执行的中文输出。
```

---

## 💡 使用建议

- 先把 `01-requirement-prompt.md` 产出的结果贴到 `{在这里粘贴需求分析结果}` 中
- 如果你已经有偏好的平台主阵地，也可以在输入中明确主平台
- 为了后面生成 skill，建议保留“单章输出结构建议”“平台模板建议”“可用于 skill 的结构化字段建议”

---

## 🧪 推荐追加信息

如你已有内容偏好，可补充如下信息：

- 主平台：小红书 / 微头条 / 知乎
- 每篇字数：100 字 / 200 字 / 300 字
- 是否保留原句
- 是否统一加结尾金句
- 是否需要标题党程度较低的标题
