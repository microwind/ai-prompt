# 第 65 章：以道治国，非以智治国

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
古之善为道者，非以明民，将以愚之。
民之难治，以其智多。
故以智治国，国之贼；
不以智治国，国之福。
知此两者，亦稽式。
常知稽式，是谓玄德。
玄德深矣，远矣，与物反矣，然后乃至大顺。
```

## 解释
**古之善为道者，非以明民，将以愚之。**
古代善于行道的人，不是教导人们耍小聪明，而是教导人们质朴纯真。

**民之难治，以其智多。故以智治国，国之贼。**
百姓之所以难管，是因为智巧伪诈的心思多了。用智谋诡计治国，是国家的祸害；

**不以智治国，国之福。知此两者，亦稽式。**
不用智谋诡计治国，才是国家的幸福。懂得这两者的差异，就是一种法则。

**常知稽式，是谓玄德。玄德深矣，远矣，与物反矣，然后乃至大顺。**
长久遵循这一法则，就叫作“玄德”。玄德深邃遥远，引导万物复归真朴，最终达到顺应自然的境界。

## 分析
本章老子提出了“反智”的治世思想。这里的“智”并非智慧，而是指投机取巧的智巧与心机。

当社会人人都耍心机、钻空子时，人与人的对抗冲突就会加剧。老子认为，真正的幸福感来源于“真诚”。以道治国，就是构建一个正直、善良的社会底色。

“玄德”是回归本原的德行。它要求我们跳出名利的争夺，保持纯粹质朴。当大家都不再通过伪诈获取利益时，社会自然会和谐顺遂。这是一种大智慧，也是大治的根本。
