# 第 62 章：道者万物之奥

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
道者，万物之奥，善人之宝，不善人之所保。
美言可以市尊，美行可以加人，人之不善，何弃之有？
故立天子，置三公，虽有拱璧以先驷马，不如坐进此道。
古之贵此道者何？
不曰求此得，有罪以免邪？
故为天下贵。
```

## 解释
**道者，万物之奥，善人之宝，不善人之所保。**
“道”是万物的庇护所。它是善良人的珍宝，也是犯过错的人的护身符。

**美言可以市尊，美行可以加人，人之不善，何弃之有？**
美好的言辞能换来尊重，善良的行为能赢得回馈。即便是不完善的人，又为什么要遗弃他们呢？

**故立天子，置三公，虽有拱璧以先驷马，不如坐进此道。**
所以，即便举行册封天子、任用重臣的大礼，捧着美玉、驾着驷马，也比不上进献这一份“大道”。

**不曰求此得，有罪以免邪？故为天下贵。**
古人之所以推崇道，不正是因为它有求必应、有罪能免吗？正因如此，它才被天下人视为最尊贵的。

## 分析
本章强调了“道”的包容性与普适性。“道”大公无私，无差别地对待众生。

我们常因个人偏好而鄙弃有过劣迹的人，但大道不偏不倚，始终提供护佑。这种博爱宽容的精神，告诫领导者不要轻易放弃任何一个百姓，而应通过感化让人重回正道。

“道”之所以贵重，在于其能救赎。在现实生活中，如果我们能学习这种宽厚，严以律己、宽以待人，不被偏见遮蔽双眼，我们便能获得内心的安宁，也能赢得真正的尊重。
