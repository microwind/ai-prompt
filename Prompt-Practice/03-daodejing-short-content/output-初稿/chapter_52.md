# 第 52 章：天下有始，以为天下母

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天下有始，以为天下母。
既得其母，以知其子；
既知其子，复守其母，没身不殆。
塞其兑，闭其门，终身不勤；
开其兑，济其事，终身不救。
见小曰明，守柔曰强。
用其光，复归其明，无遗身殃，是谓袭常。
```

## 解释
**天下有始，以为天下母。既得其母，以知其子。**
万物都有起始，这个起始就是万物的本源（道）。认识了本源，就能理解万物。

**既知其子，复守其母，没身不殆。**
理解了万物，还能守住那个本源，终身就不会有危险。

**塞其兑，闭其门，终身不勤。**
堵住耳目诱惑，关闭欲望之门，终身都不会愁苦劳累。

**见小曰明，守柔曰强。**
能洞察细微叫“明”，能坚守柔弱叫“强”。不给自己带来灾祸，这就叫承袭常道。

## 分析
本章告诫我们要返璞归真。不论时代如何变迁，人都要克制欲望。

“见小曰明”不是用眼睛看，而是用心去观察。内心清澈了，才叫明。而“守柔”则是老子一贯的主张：保持谦卑，去掉贪婪与显耀。

运用这种“内观”的智慧，将光芒回归于内心。只有守住本源，不被外物诱惑所困，人生才能走得光明而久远。
