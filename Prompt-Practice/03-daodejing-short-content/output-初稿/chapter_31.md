# 第 31 章：兵者不祥之器

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
夫兵者，不祥之器，物或恶之，故有道者不处。
君子居则贵左，用兵则贵右。
兵者不祥之器，非君子之器，不得已而用之，恬淡为上，胜而不美，而美之者，是乐杀人。
夫乐杀人者，则不可得志于天下矣。
吉事尚左，凶事尚右。
偏将军居左，上将军居右。
言以丧礼处之。
杀人之众，以悲哀莅之，战胜以丧礼处之。
```

## 解释
**夫兵者，不祥之器，物或恶之，故有道者不处。**
兵器是不吉祥的工具，人们都厌恶它，所以有道的人不使用它。

**君子居则贵左，用兵则贵右。**
君子平时以左方为贵，打仗时则以右方为贵（左为阳生，右为阴杀）。

**兵者不祥之器，非君子之器，不得已而用之，恬淡为上。**
兵器是非君子所用的东西，万不得已才使用。打仗应以恬淡、沉着为上。

**胜而不美，而美之者，是乐杀人。夫乐杀人者，则不可得志于天下矣。**
打了胜仗也不要得意洋洋，如果以此为美，那就是喜欢杀人。喜欢杀人的人，是不可能在天下实现志向的。

**战胜以丧礼处之。**
杀人众多，应以悲哀的心情对待；打了胜仗，也应按照丧礼的仪式来处理。

## 分析
本章老子旗帜鲜明地表达了反战思想。在诸侯争霸、战火不断的年代，老子痛心疾首，告诫统治者要珍惜生命，爱好和平。

“战胜以丧礼处之”，这体现了极高的悲天悯人情怀。即便得胜，也不应以嗜血为荣，而应为逝去的生命感到哀伤。这不仅是针对战争，本质上是在讲“道”的规律：不要用强权和武力去满足个人的私欲。

对于普通人，我们也应具备这种情怀。修身养性，减少暴戾之气，对生命保持基本的尊重。只有在浮躁中保持淡泊，在竞争中保持克制，才能真正获得内心的安宁。
