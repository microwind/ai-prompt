# 第 25 章：人法地，地法天，天法道，道法自然

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
有物混成，先天地生。
寂兮寥兮，独立而不改，周行而不殆，可以为天地母。
吾不知其名，强字之曰道，强为之名曰大。
大曰逝，逝曰远，远曰反。
故道大，天大，地大，人亦大。
域中有四大，而人居其一焉。
人法地，地法天，天法道，道法自然。
```

## 解释
**有物混成，先天地生。寂兮寥兮，独立而不改，周行而不殆，可以为天地母。**
有一个东西混然而成，在天地形成前就已存在。它寂静虚空，独立运行而不改变，循环往复而不歇息，可以作为万物的根源。

**吾不知其名，强字之曰道，强为之名曰大。**
我不知道它的名字，勉强称它为“道”，再勉强起个名字叫“大”。

**大曰逝，逝曰远，远曰反。**
它广大无边、运行不息，深邃遥远却又能返回本原。

**故道大，天大，地大，人亦大。域中有四大，而人居其一焉。**
所以说道大、天大、地大、人也大。宇宙间有四大，人居其一。

**人法地，地法天，天法道，道法自然。**
人效法地，地效法天，天效法“道”，而“道”效法自然（回归本原）。

## 分析
本章是老子思想的核心，完整阐述了天、地、人、道的关系，并引出了“道法自然”的最高准则。

老子指出万物是运动的、联系的，且遵循“螺旋式上升”的循环规律。这与现代科学的发展观不谋而合。人作为万物之灵，虽与天地并列，但必须遵循底层的自然规律。

“道法自然”不是落后保守，而是一种最高级的积极有为。它告诫我们要以不变应万变，在顺应客观规律的基础上进行创造。只有天人合一，人类才能实现真正的可持续发展。
