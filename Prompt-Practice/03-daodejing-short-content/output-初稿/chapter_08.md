# 第 8 章：上善若水

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
上善若水。水善利万物而不争，处众人之所恶，故几于道。
居善地，心善渊，与善仁，言善信，政善治，事善能，动善时。
夫唯不争，故无尤。
```

## 解释
**上善若水。水善利万物而不争，处众人之所恶，故几于道。**
最顶级的善就像水一样。水默默滋润万物而不与之争夺，且甘愿处于别人厌恶的低洼之地，所以最接近于“道”。

**居善地，心善渊，与善仁，言善信，政善治，事善能，动善时。**
有道的人，安于应处的地位，心胸深邃平静，待人真诚无私，说话言而有信，治理有条不紊，办事发挥才干，行动把握时机。

**夫唯不争，故无尤。**
正因为不与人争夺名利，所以才不会招致怨恨，也就没有过失。

## 分析
“上善若水”是修道的最高境界。水具有爱的奉献精神，且具备极强的包容性。在沽名钓誉、相互倾轧的时代，这种奉献精神尤为稀缺。

一个成熟的领导者或个人，应具备水一样的七种特质。其中最重要的就是“不争”。这种不争不是不作为，而是不争私利，让利于民。

当我们能像水一样，在适当的时机做正确的事，言行合一，默默奉献，自然就不会招致怨恨。这不仅是修身之德，更是处世的高级素养。
