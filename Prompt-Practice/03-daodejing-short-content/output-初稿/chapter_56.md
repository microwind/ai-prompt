# 第 56 章：知者不言，言者不知

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
知者不言，言者不知。
塞其兑，闭其门；
挫其锐，解其纷；
和其光，同其尘，是谓玄同。
故不可得而亲，不可得而疏；
不可得而利，不可得而害；
不可得而贵，不可得而贱；
故为天下贵。
```

## 解释
**知者不言，言者不知。**
真正懂的人不多言，夸夸其谈的人往往不懂。

**塞其兑，闭其门；挫其锐，解其纷；和其光，同其尘。**
堵住欲望孔窍，收敛锐气，解脱纷扰，让自己融入尘世之中。

**是谓玄同。**
这就是玄妙的融合。达到这种境界，就没有了亲疏、利害、贵贱的分别。

**故为天下贵。**
这种超越世俗偏见的状态，才是天下最尊贵的。

## 分析
“和其光，同其尘”是极高的人生智慧。

这要求我们要放下高高在上的身份，与大众紧密结合。这种“玄同”是一种无我的至高境界。

当你不再为了个人名利去计较亲疏利害时，你反而能豁然开朗。普通人若能少点私欲，顺势而为，也一定能做出一番事业。这不仅是管理策略，更是修身养性的不二法门。
