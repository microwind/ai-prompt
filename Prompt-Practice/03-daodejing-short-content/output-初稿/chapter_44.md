# 第 44 章：知足不辱，知止不殆

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
名与身孰亲？
身与货孰多？
得与亡孰病？
甚爱必大费，多藏必厚亡。
故知足不辱，知止不殆，可以长久。
```

## 解释
**名与身孰亲？身与货孰多？**
名声与生命，哪个更亲近？身体与财富，哪个更珍贵？

**得与亡孰病？甚爱必大费，多藏必厚亡。**
得到名利而失去生命，哪个更有害？过于追求必然付出巨大代价，贪得无厌必然招致沉重损失。

**故知足不辱，知止不殆，可以长久。**
懂得知足就不会遭受屈辱，懂得适可而止就不会面临危险，这样才能长久。

## 分析
老子直接点出了名利与健康的权衡。道理浅显，但世人极难做到。

人们为了财富和名望拼命工作，却往往以垮掉身体为代价。欲望无止境，贪婪无度，结果不仅失去了健康，连最初的目的也难以达成。这是典型的本末倒置。

老子的解决方案是“知足”与“知止”。建立正确的价值观，把生命和内心的宁静放在首位。只有懂得收敛，不当名利的奴隶，我们才能跳出诱惑的泥潭，获得真正的、长久的自由。
