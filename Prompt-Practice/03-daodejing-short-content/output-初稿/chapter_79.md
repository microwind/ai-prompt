# 第 79 章：天道无亲，常与善人

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
和大怨，必有余怨，安可以为善？
是以圣人执左契，而不责于人。
有德司契，无德司彻。
天道无亲，常与善人。
```

## 解释
**和大怨，必有余怨，安可以为善？**
和解深仇大怨，必然还会留下残余的积怨，这怎么能算是妥善的处理方案呢？

**是以圣人执左契，而不责于人。**
所以有道的圣人就像保存着借据（左契），却从不以此苛责他人、强迫还债。

**有德司契，无德司彻。**
有德的人像持有借据的圣人般宽厚公允，无德的人像管税的官吏般刻薄盘剥。

**天道无亲，常与善人。**
天道对任何人都没有私心偏爱，但它永远会眷顾和帮助善良的人。

## 分析
本章老子是想告诫人们要以善待人。调和矛盾的根本不在于和解的技巧，而在于“德”所带来的宽容。统治者应让利于民，而不是依仗权势盘剥。

“天道无亲，常与善人”是千古名言。虽然上天客观公正、无仁无义，但由于“德”本身就是自然法则的体现，所以善良的人自然会顺应天道，得到自然的眷顾。

读懂了这点，就能明白为什么人一定要做一个善人。多行善事，莫问前程。当你能以宽厚之心对待世界的积怨时，上天终究会给你最好的回应。这不仅是修养，更是智慧。
