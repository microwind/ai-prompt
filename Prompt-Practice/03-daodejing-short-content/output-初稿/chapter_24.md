# 第 24 章：企者不立，跨者不行

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
企者不立，跨者不行；
自见者不明，自是者不彰。
自伐者无功，自矜者不长。
其在道也，曰余食赘行。
物或恶之，故有道者不处也。
```

## 解释
**企者不立，跨者不行。**
踮起脚尖想要站得高，反而站不稳；迈开大步想要走得快，反而走不远。

**自见者不明，自是者不彰。自伐者无功，自矜者不长。**
爱自我表现的看不清真相，自以为是的得不到彰显。自我夸耀的建立不起功勋，自高自大的无法长久。

**其在道也，曰余食赘行。物或恶之，故有道者不处也。**
从“道”的角度看，这些行为就像吃剩的剩饭、多余的赘肉，令人厌恶。所以有道的人绝不这样做。

## 分析
本章是对第 22 章思想的深化。老子列举了种种“自我膨胀”的行为，并将其形象地比喻为“赘肉”。

骄傲自大的人往往内心脆弱，真正优秀的人是不屑于夸耀的。在这个充满攀比与炫耀的社交时代，老子的警示震聋发聩：违背本然的拔高，只会让人失去根基。

只有放下浮躁，静下心来与“道”为伍，踏踏实实做事，老老实实做人，才能摆脱那些令人厌恶的“赘肉”，让生命焕发出质朴而坚韧的力量。
