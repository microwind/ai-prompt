# 第 54 章：善建者不拔

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
善建者不拔，善抱者不脱，子孙以祭祀不辍。
修之于身，其德乃真；
修之于家，其德乃余；
修之于乡，其德乃长；
修之于邦，其德乃丰；
修之于天下，其德乃普。
故以身观身，以家观家，以乡观乡，以邦观邦，以天下观天下。
吾何以知天下然哉？以此。
```

## 解释
**善建者不拔，善抱者不脱。**
善于建立德行的，不可拔除；善于抱守大道的，不会脱落。

**修之于身，其德乃真；修之于家，其德乃余。**
从自身开始修德，德行才真实；以此齐家，德行就有富余。

**修之于天下，其德乃普。**
以此治理天下，德行就会广泛博大。

**吾何以知天下然哉？以此。**
我是怎么知道天下的？就是根据这种推己及人的原理。

## 分析
本章给出了修德的具体路径：由小到大，推己及人。

管理者要以身作则。从修身开始，再到家庭、邻里、国家。这个过程不能偏离大道的运行规律。

“以身观身”是一种极高的逻辑方法。通过了解万物的运行规律，我们就能洞察天下大事。不断反思内省，不失其根本，这才是君子务本的精神所在。
