# 第 46 章：知足之足，常足矣

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天下有道，却走马以粪。
天下无道，戎马生于郊。
罪莫大于可欲，祸莫大于不知足，咎莫大于欲得。
故知足之足，常足矣。
```

## 解释
**天下有道，却走马以粪；天下无道，戎马生于郊。**
治理天下遵循于“道”，战马就会退回田间耕种；治理天下违背了“道”，战马就会在战场上产崽。

**罪莫大于可欲，祸莫大于不知足，咎莫大于欲得。**
最大的罪过莫过于放纵私欲，最大的灾祸莫过于不知足，最大的过错莫过于贪得无厌。

**故知足之足，常足矣。**
所以，懂得什么时候该满足的这种满足，才是永久的满足。

## 分析
本章老子通过战争与和平的对比，告诫我们要控制欲望。人一旦贪婪成性，就会打破事物的平衡，招致灾祸。

“知足常足”不仅是个人的人生态度，更是管理者的行为准则。老子认为，统治阶级若能去掉多余的欲念，还百姓以安宁，社会自然会和谐。

这种智慧在现代社会依然具有实操性。当一个人能看清事物的“尺度”，在追求目标与实现欲望之间找到平衡，他便能拥有内心的通透与长久的安稳。
