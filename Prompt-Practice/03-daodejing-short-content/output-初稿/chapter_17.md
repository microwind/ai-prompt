# 第 17 章：功成事遂，百姓皆谓我自然

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
太上，不知有之；
其次，亲而誉之；
其次，畏之；其次，侮之。
信不足焉，有不信焉。
悠兮，其贵言。功成事遂，百姓皆谓我自然。
```

## 解释
**太上，不知有之；其次，亲而誉之；其次，畏之；其次，侮之。**
最好的领导者，百姓甚至不知道他的存在；次一等的，百姓亲近并赞美他；再次一等的，百姓畏惧他；最差的，百姓蔑视侮辱他。

**信不足焉，有不信焉。**
如果领导者的诚信不足，百姓自然就不会相信他。

**悠兮，其贵言。功成事遂，百姓皆谓我自然。**
高明的领导者悠然自得，很少发号施令。当事情办成时，百姓都觉得：“这一切原本就是自然而然发生的。”

## 分析
本章将领导者分为四个等级，其中心思想依然是“道法自然”。

最高境界的治理是“润物细无声”。最好的君王或管理者，不显摆权力，不频繁干扰，而是通过合理的机制让大家自发地工作和生活。

真正的领袖不居功，而是把利益让给百姓。这种境界虽然在现实中极难达成，但它为所有管理者指明了方向：诚信是基石，授权是智慧。最伟大的成功，是成全他人于无形之中。
