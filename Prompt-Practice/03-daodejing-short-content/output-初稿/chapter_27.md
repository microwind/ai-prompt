# 第 27 章：常善救人，故无弃人

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
善行，无辙迹；
善言，无瑕谪；
善数，不用筹策；
善闭，无关楗而不可开；
善结，无绳约而不可解。
是以圣人常善救人，故无弃人；
常善救物，故无弃物，是谓袭明。
故善人者，不善人之师；
不善人者，善人之资。
不贵其师，不爱其资，
虽智大迷，是谓要妙。
```

## 解释
**善行，无辙迹；善言，无瑕谪；善数，不用筹策。**
善于行走的，不留痕迹；善于言谈的，不留口实；善于计算的，不用筹码。

**善闭，无关楗而不可开；善结，无绳约而不可解。**
善于关闭的，不用门闩也打不开；善于捆缚的，不用绳索也解不开。

**是以圣人常善救人，故无弃人；常善救物，故无弃物，是谓袭明。**
所以圣人善于人尽其才，没有不可用之人；物尽其用，没有不可用之物。这叫作内藏的智慧。

**故善人者，不善人之师；不善人者，善人之资。不贵其师，不爱其资，虽智大迷，是谓要妙。**
善人是不善人的老师，不善人是善人的借鉴。如果不尊重老师，不珍惜借鉴，即便聪明也是大糊涂。这就是“道”的精妙之处。

## 分析
本章是“道法自然”与“无为而治”在社会领域的引申。老子用五个“善于”告诉我们：真正的智慧是顺应天性，润物无声。

在实际工作中，人们往往爱炫耀、爱算计。而老子主张“行无辙迹”，做完好事不留名，解决问题于无形。更重要的是，圣人眼中没有“废人”和“废弃物”。

善人是标杆，不善人是镜子。如果我们能以这种包容的态度对待周围的人和事，人尽其才、物尽其用，那便是掌握了“袭明”的智慧。从小处着手，做一个真正的“善人”。
