# 第 47 章：不行而知，不见而明

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
不出户，以知天下；
不窥于牖，以知天道。
其出弥远者，其知弥鲜。
是以圣人不行而知，不见而明，弗为而成。
```

## 解释
**不出户，以知天下；不窥于牖，以知天道。**
足不出户，就能知晓天下的大事；不看窗外，就能洞悉世界的规律。

**其出弥远者，其知弥鲜。**
心向外奔逐得越远，对“道”的理解反而越贫乏。

**是以圣人不行而知，不见而明，弗为而成。**
所以有道的人不走远路也能知悉天下，不用亲见也能明晓事理，不妄为而能有所成就。

## 分析
本章强调了“内观”与规律的重要性。万事万物的运行都有其底层逻辑，这就是“道”。

“足不出户”并非真的不问世事，而是通过学习前人的智慧并结合内省，掌握事物的脉络。如果你背离了规律，只是一味地向外追求感官刺激，反而会变得昏聩迷糊。

只有守住内心的清静，不为外物所惑，才能看清世界的来龙去脉。心不外驰，神守于舍，这种定力才是通往成功的基石。
