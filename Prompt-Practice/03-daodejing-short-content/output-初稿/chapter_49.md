# 第 49 章：以百姓之心为心

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
圣人恒无心，以百姓之心为心。
善者善之；不善者亦善之；德善也。
信者信之，不信者亦信之，德信也。
圣人之在天下，歙歙焉，为天下浑其心，百姓皆注其耳目焉，圣人皆咳之。
```

## 解释
**圣人恒无心，以百姓之心为心。**
有道的人没有私心，把百姓的愿望当作自己的愿望。

**善者善之；不善者亦善之；德善也。信者信之，不信者亦信之，德信也。**
善良的人，我善待他；不善良的人，我也善待他，这样人人都会向善。守信的人，我信任他；不守信的人，我也信任他，这样人人都会守信。

**圣人皆咳之。**
圣人在天下，收敛私欲，使民心回归纯朴。他像对待孩子一样善待每一位百姓。

## 分析
本章告诫领导者要去掉偏见，爱民如子。最高级的德行是无差别的博爱。

人类痛苦的根源在于欲望的膨胀。当一个人能放下私心，为了众人的利益去考虑问题时，事情往往会变得事事顺遂。

这种“以百姓之心为心”的格局，是跨越时代和国界的普世价值。只有真诚待人、将心比心，才能换取他人的真心，最终达成大治。
