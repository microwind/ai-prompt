# 第 39 章：贵以贱为本，高以下为基

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
昔之得一者：
天得一以清；地得一以宁；
神得一以灵；谷得一以盈；
万物得一以生；候王得一以为天下正。
其致之也：
天无以清，将恐裂；地无以宁，将恐废；
神无以灵，将恐歇；谷无以盈，将恐竭；
万物无以生，将恐灭；候王无以正，将恐蹶。
故贵以贱为本，高以下为基。
是以候王自称孤、寡、不谷。
此非以贱为本邪？非乎？
故至数誉，无誉。
是故不欲琭琭如玉，珞珞如石。
```

## 解释
**天得一以清；地得一以宁。万物得一以生；候王得一以为天下正。**
天得到“一”（道）而清明，地得到“一”而宁静。万物得道而生长，君王得道而天下大治。

**天无以清，将恐裂；地无以宁，将恐废。候王无以正，将恐蹶。**
如果失去大道，天会崩裂，地会震溃，君王失去正道则会倾覆。

**故贵以贱为本，高以下为基。是以候王自称孤、寡、不谷。**
所以，高贵以卑微为根本，高大以低下为基础。因此君王常自称“孤家”、“寡人”。

**是故不欲琭琭如玉，珞珞如石。**
不要追求华丽如玉，而宁愿坚实朴素如磐石。

## 分析
老子连续七次提到“一”，这里的“一”就是“道”。他认为无论自然还是社会，都必须遵循唯一的真理。

本章体现了老子“以弱胜强、以贱为本”的深刻思想。没有低贱，就没有高贵。一个领袖如果不能保持谦卑、不把自己看作普通人的一员，那他的地位就是无本之木。

我们要摒弃浮华与浮躁。在这个追逐名利的时代，保持内心的淡泊，做一个如磐石般坚韧质朴的人。这种“得一”的状态，能让我们洞悉规律，让人生变得充实稳健。
