# 第 75 章：民之饥，以其上食税之多

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
民之饥，以其上食税之多，是以饥。
民之难治，以其上之有为，是以难治。
民之轻死，以其上求生之厚，是以轻死。
夫唯无以生为者，是贤于贵生。
```

## 解释
**民之饥，以其上食税之多，是以饥。**
百姓之所以挨饿，是因为统治者征收的赋税太多，侵吞了民脂民膏。

**民之难治，以其上之有为，是以难治。**
百姓之所以难管，是因为统治者贪图功名、瞎折腾，不断干涉民生。

**民之轻死，以其上求生之厚，是以轻死。**
百姓之所以不顾性命去反抗，是因为统治者生活太奢侈、奉养太厚，逼得大家没了活路。

**夫唯无以生为者，是贤于贵生。**
只有那些不为了满足私欲而肆意妄为的人，才比那些贪图厚养生命的人更贤明。

## 分析
本章直接指出了社会动乱的根源：阶级矛盾与统治者的贪欲。百姓反抗，往往是因为生存空间被挤压到了极致。

“水可载舟，亦可覆舟”。老子告诫管理者，真正的“养生”不是享乐，而是“无以生为”，即不为了个人的供养而盘剥百姓。

一个好的管理者应从员工或百姓的角度看问题。一味压榨、奉养过厚，只会导致众叛亲离。只有藏富于民、清静自然，事业才能稳固长久。
