# 第 57 章：以正治国

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
以正治国，以奇用兵，以无事取天下。
吾何以知其然哉？以此：
天下多忌讳，而民弥贫；
民多利器，国家滋昏；
人多伎巧，奇物滋起；
法令滋彰，盗贼多有。
故圣人云：
我无为而民自化，我好静而民自正；
我无事而民自富，我无欲而民自朴。
```

## 解释
**以正治国，以奇用兵，以无事取天下。**
治国要走正道，打仗要用奇谋，赢得天下心要靠“不折腾”。

**天下多忌讳，而民弥贫。法令滋彰，盗贼多有。**
禁令越多，百姓越穷；法律条规越显眼，盗贼反而越多。

**我无为而民自化，我好静而民自正。**
只要我保持无为、清静、无事、无欲，百姓自然会变得纯朴、富庶、端正。

## 分析
本章再次讴歌了“清静无为”的好处。老子认为，治理国家应多做减法。

“多忌讳”会抹杀社会的活力。过度干预和严刑峻法，往往治标不治本。

老子的思想倾向于“小政府”。即让市场和规律发挥作用，管理者只负责公共职能与监管。这种平衡与和谐的思想，对后世的“中庸之道”产生了深远的影响。
