# 第 11 章：有之以为利，无之以为用

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
三十辐共一毂，当其无，有车之用。
埏埴以为器，当其无，有器之用。
凿户牖以为室，当其无，有室之用。
故有之以为利，无之以为用。
```

## 解释
**三十辐共一毂，当其无，有车之用。**
三十根辐条汇集在车轴的圆孔处，正因为圆孔中间是空虚的，车轮才能转动，发挥载重的作用。

**埏埴以为器，当其无，有器之用。**
揉和黏土烧制器皿，正因为器皿中间是空虚的，才能发挥盛放东西的作用。

**凿户牖以为室，当其无，有室之用。**
开凿门窗建造房屋，正因为门窗中间留有空虚之处，房屋才能发挥居住和采光通风的作用。

**故有之以为利，无之以为用。**
所以，“有”给人带来了便利条件，而“无”才真正发挥了实体的作用。

## 分析
本章老子通过车轮、器皿、房屋这三个生动的例子，论证了“有”和“无”的辩证关系。我们普通人往往只看得到看得见的“有”，却忽视了看不见的“无”。

实体的“有”固然重要，但真正起决定性作用的往往是那个空虚的“无”。这是一种质朴的哲学发现：如果没有那个空间，物体就失去了存在的价值。

这在现代生活中也有深刻的启示。就像一个人的心智，如果装满了成见、名利和琐事（全是“有”），就没有空间去吸纳新的智慧或享受内心的宁静（无）。学会给生活“留白”，给心态腾出空间，我们的能力和财富（有利）才能发挥出真正的价值（有用）。
