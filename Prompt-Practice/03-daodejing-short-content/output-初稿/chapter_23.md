# 第 23 章：希言自然

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
希言自然。
故飘风不终朝，骤雨不终日。
孰为此者？天地。
天地尚不能久，而况于人乎？
故从事于道者同于道；
德者同于德；失者同于失。
同于道者，道亦乐得之；
同于德者，德亦乐得之；
同于失者，失亦乐得之。
信不足焉，有不信焉！
```

## 解释
**希言自然。故飘风不终朝，骤雨不终日。**
少发号施令才符合自然。狂风刮不了一个早晨，暴雨下不了一整天。

**孰为此者？天地。天地尚不能久，而况于人乎？**
是谁让风雨这样的？是天地。天地的狂暴尚且不能持久，何况是人的政令与暴政呢？

**故从事于道者同于道；德者同于德；失者同于失。**
所以，按“道”行事的人就与“道”同在；按“德”行事的人就与“德”同在；失道失德的人就与“失”同在。

**同于道者，道亦乐得之；同于德者，德亦乐得之；同于失者，失亦乐得之。信不足焉，有不信焉！**
你追求什么，什么就会伴随你。如果领导者的诚信不足，自然得不到百姓的信任。

## 分析
本章强调了“道法自然”与“诚信”的重要性。老子用狂风暴雨做比喻，告诫管理者：暴力的、强干预的手段都是不能持久的。

治理企业或国家，如果动辄大刀阔斧、朝令夕改，下面的人就会疲于奔命，信任感也会随之崩溃。真正的高明是“希言”，给团队指明方向后充分授权，不要过度干预。

“同于道者，道亦乐得之”。这是一种吸引力法则。当你言必信、行必果，遵循规律办事时，资源和人才自然会聚拢在你身边。只有珍惜言行、恪守诚信，事业才能长治久安。
