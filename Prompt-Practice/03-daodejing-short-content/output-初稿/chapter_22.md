# 第 22 章：曲则全，枉则直

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
曲则全，枉则直；
洼则盈，弊则新；
少则得，多则惑，是以圣人抱一为天下式。
不自见，故明；
不自是，故彰；
不自伐，故有功；
不自矜，故长。
夫唯不争，故天下莫能与之争。
古之所谓“曲则全”者，岂虚言哉？
诚全而归之。
```

## 解释
**曲则全，枉则直；洼则盈，弊则新；少则得，多则惑。**
受得住委曲才能保全，经得起屈枉才能伸直；低洼处才能充盈，陈旧了才能更新；少取反而有得，贪多反而迷惑。

**是以圣人抱一为天下式。**
所以圣人坚守“道”的原则，作为天下人的范式。

**不自见，故明；不自是，故彰；不自伐，故有功；不自矜，故长。**
不自我表现，反而能看得清明；不自以为是，反而能是非彰显；不自我夸耀，反而能成就功勋；不自高自大，反而能长久领先。

**夫唯不争，故天下莫能与之争。**
正因为不与人争夺名利，所以天下没有人能和他相争。古人说“委曲求全”，这哪里是空话呢？它是实实在在可以达到的。

## 分析
本章老子通过六组对立关系的转化，表达了“以退为进”的处世方式。核心在于一个“不争”字。

在老子看来，“不争”才最契合“道”的本质。凡是爱表现、自大、争强好胜的行为，都违反了客观规律。真正的强者，懂得在逆境中保持谦卑，在成功时保持低调。

“夫唯不争，故天下莫能与之争。”这不是教人消极避世，而是教人以“不争”去“争”，以“无为”胜“有为”。当一个人抛却了私利与虚荣，一心顺应规律做事，他便立于了不败之地。
