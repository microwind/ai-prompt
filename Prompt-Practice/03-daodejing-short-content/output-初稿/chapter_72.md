# 第 72 章：民不畏威，则大威至矣

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
民不畏威，则大威至矣。
无狎其所居，无厌其所生。
夫唯不厌，是以不厌。
是以圣人自知不自见，自爱不自贵。
故去彼取此。
```

## 解释
**民不畏威，则大威至矣。**
当百姓不再畏惧统治者的高压威慑时，真正的、足以颠覆政权的巨大反抗就要来临了。

**无狎其所居，无厌其所生。夫唯不厌，是以不厌。**
不要逼迫人民不得安居，不要阻塞人民谋生的道路。只有统治者不压迫百姓，百姓才不会厌恶统治者。

**是以圣人自知不自见，自爱不自贵。故去彼取此。**
所以圣人有自知之明而不自我表现，自珍自爱而不显摆高贵。舍弃表面的张扬，保持内在的清醒。

## 分析
本章告诫管理者要认清人民的力量。民以食为天，以生为本。如果人们连生计都无法维持，高压政策就失去了作用。

“民不畏死”是因为走投无路。源头上看，压榨与欺凌才是祸乱之首。一个自重、自爱的领导者，不会把地位当作作威作福的工具，而是会通过利益分享赢得民心。

我们要去掉那些虚荣的显摆，回归质朴。只有尊重他人的生存空间，不滥用权威，才能赢得长久的归顺与和谐。
