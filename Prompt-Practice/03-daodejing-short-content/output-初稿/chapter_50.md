# 第 50 章：摄生

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
出生入死。
生之徒，十有三；
死之徒，十有三；
人之生，动之死地，亦十有三。
夫何故﹖以其生生之厚。
盖闻善摄生者，陆行不遇兕虎，
入军不被甲兵；
兕无所投其角，
虎无所措其爪，
兵无所容其刃。
夫何故﹖以其无死地。
```

## 解释
**出生入死。**
人始于出世，终于死亡。

**生之徒，十有三；死之徒，十有三；人之生，动之死地，亦十有三。**
长寿者占三成，夭折者占三成，本来能活却因为折腾作死的人也占三成。

**夫何故﹖以其生生之厚。**
这是为什么呢？因为他们生养过于优厚，欲望太强了。

**夫何故﹖以其无死地。**
善于养生的人，猛兽伤不了他，武器也害不了他。这是因为他顺应自然，不让自己陷入危险的境地。

## 分析
本章通过生死的规律，告诫我们要遵循自然，适可而止。

很多人为了长生不老或者享受荣华而“生生之厚”，结果反而透支了生命。真正的“善摄生者”，是那些懂得舍弃欲望、顺势而为的人。

不入险境、不贪虚名，这样的人没有所谓的“死穴”。保持内心的纯真与质朴，就能在复杂的环境中化解灾祸，走完自然的生命旅程。
