# 第 16 章：致虚极，守静笃

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
致虚极，守静笃，万物并作，吾以观复。
夫物芸芸，各复归其根。归根曰静，是谓复命。
复命曰常，知常曰明，不知常，妄作，凶。
知常容，容乃公，公乃王，王乃天，天乃道，道乃久，没身不殆。
```

## 解释
**致虚极，守静笃，万物并作，吾以观复。**
达到虚空的极致，笃守清静的极致。万物都在蓬勃生长，我从中观察循环往复的规律。

**夫物芸芸，各复归其根。归根曰静，是谓复命。**
万物繁杂，最终都要各自回归本根。回归本根叫作“静”，也就是回归生命的本质。

**复命曰常，知常曰明，不知常，妄作，凶。**
回归本性是永恒的规律，认识规律叫作“明”。如果不认识规律而轻举妄动，就会招致灾祸。

**知常容，容乃公，公乃王，王乃天，天乃道，道乃久，没身不殆。**
认识规律后就能包容万物，能包容就能公正，公正才能周全，周全才符合自然与天道。符合天道才能恒久，终身没有危险。

## 分析
本章指出了“道”的核心：返回本根，追求极致的虚空与清静。这并非消极逃避，而是一种在大智慧中的“担当”。

“清静无为”是老子的核心。这种静不是形式上的打坐，而是抛弃私欲、笃守内心。只有静下心来，才能看清事物“复归其根”的规律。

在浮躁的社会中，不知规律而盲目奋斗，往往是“妄作”。只有看清常理，心怀宽容与公正，我们才能在动荡中保持定力。老老实实做人，按规律办事，这才是真正的“明”，才能让生命长久安稳。
