# 第 36 章：柔弱胜刚强

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
将欲歙之，必固张之；
将欲弱之，必固强之；
将欲废之，必固兴之；
将欲取之，必固与之。
是谓微明，柔弱胜刚强。
鱼不可脱于渊，邦之利器不可以示人。
```

## 解释
**将欲歙之，必固张之；将欲弱之，必固强之。**
想要收缩它，必先扩张它；想要削弱它，必先增强它。

**将欲废之，必固兴之；将欲取之，必固与之。**
想要废除它，必先兴盛它；想要夺取它，必先给予它。

**是谓微明，柔弱胜刚强。**
这就是深微高明的道理：柔弱能够胜过刚强。

**鱼不可脱于渊，邦之利器不可以示人。**
鱼不能离开深潭，国家的强大力量（利器）不能轻易炫耀示人。

## 分析
本章展示了高深的辩证法与战略思维。老子认为，事物在达到极限时必然向反面转化。

“欲取先予”是一种出其不意的智慧。面对强大的对手，不必硬碰硬，可以先使其骄纵狂妄，待其物极必反时再一举胜之。这种以退为进、韬光养晦的策略，在竞争中极具借鉴意义。

同时，人要守住自己的根本（渊）。不要轻易展示底牌或炫耀力量，保持低调、柔静与弱小，才是真正的自我保护。
