# 第 48 章：为道日损

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
为学日益，为道日损。
损之又损，以至于无为。
无为而无不为。
取天下常以无事，及其有事，不足以取天下。
```

## 解释
**为学日益，为道日损。**
求学的人，知识一天比一天增加；求道的人，私欲一天比一天减少。

**损之又损，以至于无为。无为而无不为。**
私欲减少再减少，就达到了“无为”的境地。无为表面上没有作为，实际上无所不为。

**取天下常以无事，及其有事，不足以取天下。**
治理天下要以不骚扰民生为本；如果经常人为干预、滋扰百姓，就不配治理天下了。

## 分析
本章提出了著名的“日益”与“日损”的观点。求学是做加法，而修道是做减法。

“损”的过程，就是不断舍弃贪欲、偏见和智巧的过程。当我们不再被这些外物束缚时，心力反而能自然爆发，达成“无不为”的结果。

管理国家或企业也是如此。管理者应遵循减法原则，少一点花活，多一点支持。不瞎折腾，团队反而能自发地创造价值。这种简单的智慧，才是长治久安的根本。
