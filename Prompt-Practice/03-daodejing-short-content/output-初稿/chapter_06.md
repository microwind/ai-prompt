# 第 6 章：谷神不死

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
谷神不死，是谓玄牝。
玄牝之门，是谓天地根。
绵绵若存，用之不勤。
```

## 解释
**谷神不死，是谓玄牝。**
永恒长存的“道”（谷神）是生养万物的玄妙母体。

**玄牝之门，是谓天地根。**
这个玄妙母体的生殖产门，就是天地生成的根源。

**绵绵若存，用之不勤。**
它绵延不绝地存在着，作用无穷无尽，永远不会枯竭。

## 分析
老子用母性来比拟“道”，指出其虚空而能生养、绵延且不绝的特性。万物皆有生灭，唯有创造万物的规律永恒长存。

这种“用之不勤”的思想，提醒我们要敬畏根源。老子用母性做比，也是让我们尊敬母性，引申出对传统的尊重。

虽然“道”的定义在文字上显得玄妙，但它本质上指明了世界存在的客观性。理解了这种生生不息的循环，我们才能在变化中找到那份恒久不变的定力。
