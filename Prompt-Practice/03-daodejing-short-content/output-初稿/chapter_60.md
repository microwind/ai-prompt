# 第 60 章：治大国若烹小鲜

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
治大国，若烹小鲜。
以道莅天下，其鬼不神。
非其鬼不神，其神不伤人。
非其神不伤人，圣人亦不伤人。
夫两不相伤，故德交归焉。
```

## 解释
**治大国，若烹小鲜。**
治理大国，就像烹饪小鱼一样。

**以道莅天下，其鬼不神。非其鬼不神，其神不伤人。**
用“道”来治理天下，鬼怪也就不灵验了。即便灵验，也不会伤人。

**非其神不伤人，圣人亦不伤人。**
不仅鬼神不伤人，得道的统治者也不会伤害百姓。

**夫两不相伤，故德交归焉。**
各方都不互相伤害，德行就会交融，归于大道。

## 分析
“治大国若烹小鲜”是千古名言。它的真意是：不要反复折腾。

煎小鱼如果不停翻动，鱼就会碎掉。治理国家也要顺应自然，火候要稳。管理者应把“道”作为主体，发挥人的主观能动性去辅佐它，而不是破坏规律。

当社会依循正道，各方以“德”相待，就会进入一种良性循环。这种“互不相伤”的状态，才是天下大治的最高理想。
