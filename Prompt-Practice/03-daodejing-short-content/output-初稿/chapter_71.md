# 第 71 章：知不知，上

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
知不知，上；
不知知，病。
夫唯病病，是以不病。
圣人不病，以其病病，是以不病。
```

## 解释
**知不知，上；不知知，病。**
知道自己还有所不知，这是最高明的；不知道却自以为知道，这就是一种病态。

**夫唯病病，是以不病。**
只有把这种病态当成病去医治（引以为戒），才不会犯这种病。

**圣人不病，以其病病，是以不病。**
圣人之所以没有这种缺点，是因为他能直面自己的不足并时刻警惕，所以才不会犯这种糊涂。

## 分析
本章指出了人性的普遍弱点：自以为是。真正入道的人，始终保持着求知的精神，即使有所成就，也会虚怀若谷。

这与苏格拉底的“认识无知”以及孔子的“知之为知之”异曲同工。领导者若刚愎自用、不懂装懂，就会被事物的表象蒙蔽，导致判断失误。

“夫唯病病”是自我修正的智慧。承认缺陷、不断改进，这就是求道的精神。保持实事求是的心态，不断自我提升，才能让内心光明纯净，不被外物所扰。
