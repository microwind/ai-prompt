# 第 45 章：大巧若拙，大辩若讷

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
大成若缺，其用不弊。
大盈若冲，其用不穷。
大直若屈，大巧若拙，大辩若讷。
躁胜寒，静胜热，清静为天下正。
```

## 解释
**大成若缺，其用不弊。大盈若冲，其用不穷。**
最伟大的成就看起来好像有缺陷，但它的作用却永不衰竭；最圆满的充盈看起来好像空虚，但它的作用无穷无尽。

**大直若屈，大巧若拙，大辩若讷。**
最刚直的好像弯曲，最灵巧的好像笨拙，最有口才的好像木讷。

**躁胜寒，静胜热，清静为天下正。**
动作可以战胜寒冷，安静可以克服燥热。清静无为才是治理天下的正道。

## 分析
本章包含了极其深刻的辩证思维：极致的完美，往往带有缺憾。

当我们追求完美无缺时，老子告诉我们要“抱朴守拙”。那种急于表现智巧、急于展现能言善辩的行为，往往容易背离本真。真正的聪明人，看起来往往有点笨拙；真正的胜者，内心始终保持宁静。

“清静为天下正”。在浮躁喧嚣的世界里，我们更应坚守内心的淡泊。不论身处何位，保持一份“守中”的定力，尽心尽力做好每一天，这才是通往成功的正道。
