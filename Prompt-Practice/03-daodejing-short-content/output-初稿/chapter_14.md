# 第 14 章：执古之道，以御今之有

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
视而不见，名曰夷；听之不闻，名曰希；
搏之不得，名曰微。此三者不可致诘，故混而为一。
其上不徼，其下不昧，绳绳兮不可名，复归于无物。
是谓无状之状，无物之象，是谓惚恍。
迎之不见其首，随之不见其后。
执古之道，以御今之有。能知古始，是谓道纪。
```

## 解释
**视而不见，名曰夷；听之不闻，名曰希；搏之不得，名曰微。**
看不见，叫作“夷”；听不到，叫作“希”；摸不着，叫作“微”。这三者的形态无法深究，它们本就是浑然一体的。

**其上不徼，其下不昧，绳绳兮不可名，复归于无物。**
它的上面并不明亮，下面也不黑暗，绵延不绝无法描述，最终又回到了虚空的无物状态。

**是谓无状之状，无物之象，是谓惚恍。迎之不见其首，随之不见其后。**
这就是没有形状的形状，没有实体的形象，叫作“惚恍”。迎着它看不见头，跟着它看不见尾。

**执古之道，以御今之有。能知古始，是谓道纪。**
秉持自古存在的“道”，来治理和观察现今的事物。能了解宇宙的起始规律，这就是“道”的纲要。

## 分析
本章老子试图描述“道”那不可感知的特质。它看不见、听不到、摸不着，却真实存在并支配着万物。

“执古之道，以御今之有”是极具现实意义的智慧。虽然时代变迁、技术革新，但事物运行的底层逻辑（道）自古至今并未改变。

通过掌握本质规律，我们才能在瞬息万变的世界中洞察真相。这种追求本质的精神，是驾驭复杂局面的关键。不论面对多么复杂的新事物，只要能追根溯源，识得“道纪”，便能豁然开朗。
