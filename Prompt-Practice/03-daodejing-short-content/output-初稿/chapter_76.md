# 第 76 章：强大处下，柔弱处上

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
人之生也柔弱，其死也坚强；
草木之生也柔脆，其死也枯槁。
故坚强者死之徒，柔弱者生之徒。
是以兵强则灭，木强则折。
强大处下，柔弱处上。
```

## 解释
**人之生也柔弱，其死也坚强；草木之生也柔脆，其死也枯槁。**
人活着的时候身体是柔软的，死了以后身体就变得僵硬；草木生长的时候也是柔韧脆弱的，死了以后就变得干枯坚硬。

**故坚强者死之徒，柔弱者生之徒。**
所以说，僵硬死板属于死亡的一类，柔弱灵动属于生命的一类。

**是以兵强则灭，木强则折。强大处下，柔弱处上。**
因此，用兵逞强反而会招致灭亡，树木过于坚硬就容易折断。过于强大的往往处于劣势，保持柔弱的反而占据优势。

## 分析
这一章老子通过观察自然现象，阐释了“柔弱胜刚强”的客观法则。不论是人还是草木，生命力旺盛的标志都是“柔”。一旦走向僵硬，往往预示着生命力的流逝。

事物过于强大了都会走向反面，这是“道”的运行规律。在相对的竞争中，强者容易滋生骄傲自满，从而变得僵化、脆弱（处下）；而弱者因为谦虚谨慎、身段灵活，反而能在变化中保存实力，占据主动（处上）。

学习老子的智慧，切忌将“柔弱”看作胆小或保守。它其实是一种更高级的积极有为，要求我们在遵循规律的基础上，保持心态的开放与身段的灵活。不逞强、不妄为，才能在变幻莫测的环境中保持长久的生命力。
