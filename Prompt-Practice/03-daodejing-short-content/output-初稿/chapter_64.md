# 第 64 章：慎终如始

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
其安易持，其未兆易谋；
其脆易泮，其微易散。
为之于未有，治之于未乱。
合抱之木，生于毫末；
九层之台，起于垒土；
千里之行，始于足下。
为者败之，执者失之。
是以圣人无为故无败，无执故无失。
民之从事，常于几成而败之。
慎终如始，则无败事。
是以圣人欲不欲，不贵难得之货；
学不学，复众人之所过。
以辅万物之自然而不敢为。
```

## 解释
**其安易持，其未兆易谋。为之于未有，治之于未乱。**
局面安定时容易维持，苗头未显时容易谋划。事情要在发生前处理，祸乱要在产生前治理。

**合抱之木，生于毫末；九层之台，起于垒土；千里之行，始于足下。**
大树长于萌芽，高台起于泥土，千里的远行始于脚下的第一步。

**民之从事，常于几成而败之。慎终如始，则无败事。**
人们做事，往往在快成功时失败。如果到结束时仍能像开始一样慎重，就不会失败。

**是以圣人欲不欲，学不学，以辅万物之自然而不敢为。**
所以圣人以无欲为欲，以不学为学，补救众人的过失，顺应万物的本性而不敢妄加干预。

## 分析
本章是上一章思想的延续。强调了量变到质变的过程，以及坚持到底的重要性。

“慎终如始”是千古名言。很多人失败不是因为没能力，而是因为缺乏持久的敬畏心。当接近目标时，人容易松懈、狂妄，最终功亏一篑。

老子主张“无执”。即顺应自然规律办事，不固执己见。所谓的“不学”和“无欲”，是跳出教条的枷锁，从底层逻辑去复盘和修正。只有守住那份最初的谨慎，持之以恒，才能最终辅佐万物自然成就。
