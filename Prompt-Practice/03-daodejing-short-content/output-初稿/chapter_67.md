# 第 67 章：我有三宝，持而保之

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天下皆谓我道大，似不肖。夫唯大，故似不肖。
若肖，久矣其细也夫！
我有三宝，持而保之：
一曰慈；二曰俭；三曰不敢为天下先。
慈，故能勇；俭，故能广；不敢为天下先，故能成器长。
今舍其慈，且勇；舍其俭，且广；舍其后，且先，死矣。
夫慈，以战则胜，以守则固。天将救之，以慈卫之。
```

## 解释
**天下皆谓我道大，似不肖。我有三宝，持而保之。**
天下人都说我的“道”太宽广，不像具体的实物。正因为宽广，才没有具体的形象。我有三件法宝，始终保有它们：

**一曰慈；二曰俭；三曰不敢为天下先。**
第一叫仁慈，第二叫俭朴，第三叫不敢争在天下人的前面。

**慈故能勇；俭故能广；不敢为天下先，故能成器长。**
仁慈所以能生出真正的勇敢；俭朴所以能变得宽广；不争先所以能引领万物。

**舍其慈且勇，舍其俭且广，舍其后且先，死矣。**
如果丢掉仁慈追求凶狠，丢掉俭朴追求奢华，丢掉退让追求争先，那就是走向死亡。上天要救赎谁，一定会用仁慈来保护他。

## 分析
老子提出了人生的三大原则：慈、俭、让。

“慈”是核心。它不仅是情感，更是无畏的力量。像母亲保护孩子，慈爱能激发人最强大的潜能。而“俭”是对欲望的克制，只有生活朴素，内心才能宽广长久。

“不敢为天下先”是针对私利而言。遇事让利，遇难担当。这三大法宝是“无为”的实施手册。如果领导者舍本逐末，追求强力与奢靡，最终只会走上绝路。守住慈悲与俭朴，才是真正的长青之道。
