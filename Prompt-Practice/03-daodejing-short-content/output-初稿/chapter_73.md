# 第 73 章：天网恢恢，疏而不失

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
勇于敢则杀，勇于不敢则活。
此两者，或利或害。
天之所恶，孰知其故？
是以圣人犹难之。
天之道，不争而善胜，不应而善应，不召而自来，繟然而善谋。
天网恢恢，疏而不失。
```

## 解释
**勇于敢则杀，勇于不敢则活。**
勇敢而无所敬畏（乱来），往往招致死亡；勇敢而心存敬畏，反而能保全生命。

**天之所恶，孰知其故？是以圣人犹难之。**
上天厌恶什么，谁知道原因呢？所以圣人做事总是小心翼翼，有所顾忌。

**天之道，不争而善胜，不应而善应，不召而自来，繟然而善谋。**
上天的规律是：不去争夺而能取胜，不发号施令而有人响应，无需召唤而百姓自来，从容坦然而善于谋划。

**天网恢恢，疏而不失。**
大道宽广无边，虽然看起来稀疏，却绝不会漏失任何一个奖惩。

## 分析
本章强调了“敬畏心”。“勇”是一种魄力，但必须依循于“道”，不可逆天而行。

那些肆无忌惮、胆大妄为的人，终究逃不过客观规律的制约。真正的“天道”是顺其自然，是“无为”的高级谋划。这种规律虽然气息微弱，却公正无私。

我们做事情既要具备勇气，也要敬天爱人。在迅猛发展的现代社会，只有保持对规则和自然的敬畏，才能用最少的代价，获得最长久的收益。
