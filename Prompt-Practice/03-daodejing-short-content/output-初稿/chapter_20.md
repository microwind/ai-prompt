# 第 20 章：我独异于人，而贵食母

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
唯之与阿，相去几何？善之与恶，相去若何？
人之所畏，不可不畏。
荒兮，其未央哉！
众人熙熙，如享太牢，如春登台。
我独泊兮，其未兆；沌沌兮，如婴儿之未孩；儽儽兮，若无所归。
众人皆有余，而我独若遗。我愚人之心也哉！
俗人昭昭，我独昏昏。俗人察察，我独闷闷。
澹兮其若海，飂兮若无止。
众人皆有以，而我独顽且鄙。我独异于人，而贵食母。
```

## 解释
**唯之与阿，相去几何？善之与恶，相去若何？人之所畏，不可不畏。**
恭敬的应答与傲慢的呵斥，相差多少？美与丑，相差又有多少？众人所畏惧的事物，我也不得不敬畏。

**众人熙熙，如享太牢，如春登台。我独泊兮，其未兆；沌沌兮，如婴儿之未孩。**
世人都兴高采烈，好像参加盛大的祭祀，又像春天登台眺望。唯独我淡泊宁静，无动于衷；质朴得就像还不会笑的婴儿。

**众人皆有余，而我独若遗。俗人昭昭，我独昏昏。俗人察察，我独闷闷。**
众人都有所盈余，唯独我好像有所遗失。世人都明明白白，唯独我昏昏沉沉；众人都精明干练，唯独我不声不响。

**众人皆有以，而我独顽且鄙。我独异于人，而贵食母。**
世人都大有作为，唯独我愚昧粗鄙。我唯一与众不同的，就是推崇那孕育万物的根源——“道”。

## 分析
本章通过强烈的对比，展现了修道者与世俗众生的巨大反差。“众人”皆醉“我”独醒，这是一种笃静守拙的处世哲学。

在人人争名夺利、精于算计的时代，守住那份“昏昏闷闷”的孤独是非常难的。这种“愚笨”其实是大智慧，是不随波逐流的定力。

“贵食母”即推崇万物之母。修道之人不求光彩照人，只求默默奉献。像大海一样宁静，像风一样灵动。只要我们能遵循规律并踏实付出，内心就会获得真正的充盈。
