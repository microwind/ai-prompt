# 第 55 章：比于赤子

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
含德之厚，比于赤子。
毒虫不螫，猛兽不据，攫鸟不搏。
骨弱筋柔而握固。
未知牝牡之合而朘作，精之至也。
终日号而不嗄，和之至也。
知和曰常，知常曰明，益生曰祥，心使气曰强。
物壮则老，谓之不道，不道早已。
```

## 解释
**含德之厚，比于赤子。**
道德修养深厚的人，好比刚出生的婴儿。

**毒虫不螫，猛兽不据，攫鸟不搏。**
毒虫不咬他，猛兽不伤他，凶鸟不抓他。

**骨弱筋柔而握固。终日号而不嗄，和之至也。**
他筋骨柔弱但抓握有力，整天啼哭但嗓子不哑，这是因为他精力充沛、和气醇厚。

**物壮则老，谓之不道，不道早已。**
事物过于壮大就会走向衰老，这叫不符合“道”，不符合“道”很快就会灭亡。

## 分析
老子把得道之人比作赤子。赤子无欲无为，所以不会引来外界的攻击。

“物壮则老”是本章的警钟。凡事过犹不及，保持合适的状态才是最重要的。这并不是教人不思进取，而是告诫我们不要妄为。

该出手时就出手，但一定要守住那份谦卑与虔诚。只有回归初心，保持那份纯真，才能在变幻莫测的世事中，洞察规律，立于不败之地。
