# 第 41 章：大器晚成，大音希声

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
上士闻道，勤而行之；
中士闻道，若存若亡；
下士闻道，大笑之。
不笑，不足以为道。
故建言有之：
明道若昧，进道若退，夷道若颣。
上德若谷；大白若辱；
广德若不足；建德若偷；质真若渝。
大方无隅；大器晚成；
大音希声；大象无形；
道隐无名。
夫唯道，善贷且成。
```

## 解释
**上士闻道，勤而行之；下士闻道，大笑之。不笑，不足以为道。**
高明的人听了道就努力去实践；浅薄的人听了道就哈哈大笑。如果不被嘲笑，那就不足以称为“道”了。

**明道若昧，进道若退，夷道若颣。**
光明的道看起来暗昧，进步的道看起来像退步，平坦的道看起来像崎岖。

**大方无隅；大器晚成；大音希声；大象无形。**
最方正的没有棱角，最贵重的器皿最后制成，最大的声音听不到声音，最大的形象没有形状。

**道隐无名。夫唯道，善贷且成。**
“道”隐没无形，无声无名。只有它，能让万物善始善终。

## 分析
本章描绘了不同层次的人对待真理的态度。由于“道”往往是反直觉的，所以才容易被平庸之辈嘲笑。

老子论证了矛盾的对立统一：真正的上德往往表现得低下，真正的质朴看起来像浑浊。这种内心的修炼，是不求名利、没有私心的。

要想认识事物的本质，就不能被表象蒙蔽。只有了解事物背后那隐藏的“道”，熟悉它的运行规律，我们才能在复杂的社会中，做到大器晚成、大音希声。
