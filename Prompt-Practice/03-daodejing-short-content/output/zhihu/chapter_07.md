# 第 7 章：天长地久，不自生故能长生
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天长，地久。
天地之所以能长且久者，以其不自生也，故能长生。
是以圣人后其身而身先，外其身而身存。
非以其无私邪（yé）？故能成其私。
```

## 解释
**天长地久。天地之所以能长且久者，以其不自生也，故能长生。**
天长地久，天地之所以能够永恒存在，是因为它们运行不息并非为了自身的私利，而是自然而然地生养万物，所以才得以长久。

**是以圣人后其身而身先，外其身而身存。**
因此，有道的治理者将自身置于他人之后，结果反而能在众人中领先；将自身安危置之度外，结果反而能保全自身。

**非以其无私邪？故能成其私。**
这难道不正是因为他的无私吗？正因为他没有私心，反而成就了他的个人价值与目标。

## 分析
**逻辑洞察：**
本章阐述了“无私”与“长久”的辩证逻辑。天地作为系统的环境，通过“不自生”（不消耗系统红利为己用）实现了系统的可持续运行。圣人效法天地，通过“后其身”与“外其身”，构建了一个极高的个人信用与社会契约，从而在博弈中获得了最优解。

**第一性原理思考：**
在博弈论中，长期利益的获得往往需要对短期利益的舍弃。老子所说的“无私而成其私”，本质上是跨时间尺度的利益最大化。当一个个体能超越眼前的“小私”，将行为锚定在公众利益或系统规律上时，他便获得了某种形式的“不灭”。这不仅是道德律令，更是生存的高维法则。

**认知启发：**
“利他”即是最高境界的“利己”。在现代社会中，个人的影响力往往取决于他能成就多少人。当你能做到“先天下之忧而忧，后天下之乐而乐”时，你不仅赢得了声望，更赢得了他人自发的拥护（身先）。这种因无私而产生的领导力，才是最稳固且不可动摇的。
