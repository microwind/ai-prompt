# 第 9 章：功遂身退，天之道也
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
持而盈之，不若其已；
揣（zhuī）而锐之，不可长保。
金玉满堂，莫之能守；
富贵而骄，自遗其咎（jiù）。
功遂身退，天之道也。
```

## 解释
**持而盈之，不若其已；揣而锐之，不可长保。**
执持盈满的器皿而仍不停止，不如适可而止。将铁器捶打得过于锐利，其锋芒反而难以持久。

**金玉满堂，莫之能守；富贵而骄，自遗其咎。**
即便金玉堆满厅堂，也无法长久守住；富贵之后若滋生骄横之气，则是为自己埋下祸端。

**功遂身退，天之道也。**
在功成名就之时懂得急流勇退，这才是顺应自然天道的表现。

## 分析
**逻辑洞察：**
本章阐述了“物极必反”的系统热力学规律。老子指出，任何事物在达到极值后，继续增加输入的边际效应不仅为负，甚至会引发系统的崩溃（自遗其咎）。“盈”与“锐”是系统的不稳定状态，通过“已”与“退”，可以实现系统能位的平稳转换，从而保全已有的成果。

**第一性原理思考：**
在博弈与组织管理中，权力的顶点往往意味着风险的顶点。老子提倡的“功遂身退”，本质上是一种对风险的对冲。当个人或组织的边际收益开始下降，而边际风险剧增时，主动降低能位、稀释权力或转移关注点，是确保生存的最佳策略。这种对“度”的精准把控，是顶级认知力的体现。

**认知启发：**
保持“不满”的状态是持续成长的必要条件。明白“富不过三代”或“花无百日红”的规律，能让我们在顺境中保持审慎。在现代职场中，不刻意追求锋芒毕露，不迷恋权位，将精力转向智慧的传承与思想的沉淀，方能实现“身退而名存”。守住适度的平衡，即是守住了天道。
