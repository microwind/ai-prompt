# 第 6 章：谷神不死 | 世界上最持久的力量，往往最温柔
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
谷神不死，是谓玄牝（pìn）。
玄牝之门，是谓天地根。
绵绵若存，用之不勤。
```

## 解释
**谷神不死，是谓玄牝。**
“谷”是虚空的，“神”是神奇的。规律就像大山谷里的生机，永远不会消失。它又像一个伟大的母亲，孕育出这世间的一切。

**玄牝之门，是谓天地根。**
这个母体的出入口，就是天地万物的根。万物就像孩子一样，从这里被创造出来。

**绵绵若存，用之不勤。**
它的作用是绵绵不断的，你看不见它，但它就在那儿起作用，而且怎么用都用不完。

## 分析
【现实逻辑】
老子这章其实在赞美“生命力”。他发现，最硬的东西容易折断，而最虚、最柔的东西反而最持久。就像一个家庭，母亲的包容往往是这个家能长久维系的“根”。

【案例拆解】
看看现在的互联网生态，那些真正活得久的企业，都不是靠搞垄断、搞霸权活下来的，而是靠“生态包容”。他们提供平台（谷），让无数创业者在上面生长（牝）。这种力量看似温和、不显眼，但它极其坚韧，取之不尽。这就是“用之不勤”。

【生活智慧】
不要总想着当那个“最强”的人，要试着当那个最能“承载”的人。尊重女性，尊重母亲，因为母性中蕴含着与“道”最接近的创造规律。在日常生活中，保持一份内心的空灵和生机，做事不急于求成，细水长流才是真本领。
