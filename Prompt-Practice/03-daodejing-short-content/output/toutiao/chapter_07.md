# 第 7 章：无私成其私 | 财散人聚，越不争的人得到越多
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天长，地久。
天地之所以能长且久者，以其不自生也，故能长生。
是以圣人后其身而身先，外其身而身存。
非以其无私邪（yé）？故能成其私。
```

## 解释
**天长地久。**
天地长久存在，是因为它们不为了自己的私利而活着，而是自然地运行，养育万物。这种大公无私，才让它们长生。

**后其身而身先，外其身而身存。**
聪明的领导者遇事让别人占先，不与百姓争利，反而能赢得爱戴，大家都会推举他走在前面。凡事把个人利益置之度外，在危险面前身先士卒，反而能保全生命。

**非以其无私邪？故能成其私。**
这不正是因为无私吗？正因为不自私，最后反而成全了自己的利益和名望。

## 分析
【现实逻辑】
老子这章讲的是“舍与得”。你越是抓得紧，越容易失去；你越是懂得放手、懂得利他，最后得到的反而越多。这就像现在的“财散人聚”，一个老板舍得给员工发钱、分红，最后企业才能做大，老板赚得也更多。

【案例拆解】
看看那些被历史铭记的人物，像尧舜禹，或者咱们近现代那些为民谋福的先辈。他们当时都是“外其身”，根本没想过给自己留什么。结果呢？他们永远活在老百姓心中。这就是“长生”。相反，那些自私自利、搜刮民财的人，很快就被唾弃了。

【生活智慧】
做人不要太“抠搜”。在日常生活中，多一点谦让，少一点计较。在职场里，多帮帮同事，别怕吃亏。你要明白，所有的“利他”最后都会回流到你自己身上。无私，才是最高级的自私。
