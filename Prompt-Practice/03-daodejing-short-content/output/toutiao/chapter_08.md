# 第 8 章：上善若水 | 真正聪明的人，都活得像水一样
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
上善若水。水善利万物而不争，处众人之所恶（wù），故几（jī）于道。
居善地，心善渊，与善仁，言善信，政善治，事善能，动善时。
夫唯不争，故无尤。
```

## 解释
**上善若水。**
最好的德行就像水。水滋润万物，却不求回报，也不跟万物争高下。它专门去别人不愿去的低洼处，这种品性最接近“道”。

**七个“善”：**
找准自己的位置，心胸开阔深沉，待人真诚，说话算数，管理有方，做事能干，抓住时机。

**夫唯不争，故无尤。**
只要你不跟别人盲目争名夺利，你就不会招来怨恨，也就不会犯什么大错。

## 分析
【现实逻辑】
老子这章把水的性格拆解得特别透。为什么水厉害？因为它灵活。给它个杯子它就是杯子的形状，给它个盆它就是盆的形状。它不硬碰硬，但最后总能流到想去的地方。

【案例拆解】
看看现在的创业环境，那些天天在媒体上“叫嚣”的公司，往往倒得快。反而是那些默默深耕用户需求、解决行业痛点的公司，活得最滋润。他们就像水，平时看不见，但你离不开。等到时机一成熟（动善时），他们就爆发了。

【生活指南】
做人要有“水德”。别总想着出风头，别怕干那些累活、脏活（处众人之所恶）。在单位里，做一个靠谱、能干、说话算数的人。当你像水一样能利万物时，大家都离不开你，你还用得着去“争”吗？不争，才是最大的争。
