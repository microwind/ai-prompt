# 第 4 章：挫其锐，解其纷 | 真正厉害的人，从不显山露水
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
道冲而用之或不盈，渊兮似万物之宗。
挫其锐，解其纷，和其光，同其尘。
湛（zhàn）兮似或存。
吾不知谁之子，象帝之先。
```

## 解释
**道冲而用之或不盈。**
大道就像一个空荡荡的容器，看起来啥也没有，但用起来却无穷无尽，永远装不满。

**挫其锐，解其纷，和其光，同其尘。**
它磨掉了锐气，化解了纷扰，隐藏了光芒，把自己混同在普普通通的尘土之中。它就在我们身边，非常接地气。

**湛兮似或存。**
它深沉而静谧，虽然看不见摸不着，但却真实地主宰着万物的生长。

**吾不知谁之子，象帝之先。**
我不知道它是谁产生的，它似乎比人类想象中的天帝还要古老。

## 分析
【现实逻辑】
老子在讲“规律”的低调。你看空气、水、重力，这些最重要的东西往往都是看不见的。真正的底层规律从不显摆自己，它只是默默地起作用。

【案例拆解】
很多企业做大后就容易“膨胀”，到处秀肌肉，结果很快就被竞争对手针对。这就是“锐气”太重。而那些真正长青的企业，往往深谙“同其尘”的道理，低调做产品，解决用户的实际痛点，不被名利纷扰干扰。这就是“解其纷”。

【生活智慧】
做人不要太“刺儿”。收敛起那些刺眼的光芒，学会和不同层次的人打交道。大隐隐于市，在平凡的生活中去感悟那个不平凡的“道”。当你能跳出固有思维，从更高的维度看世界，你也就接近了事物的本质。
