# 第 9 章：功遂身退 | 别在最好的时候把路走绝
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
持而盈之，不若其已；
揣（zhuī）而锐之，不可长保。
金玉满堂，莫之能守；
富贵而骄，自遗其咎（jiù）。
功遂身退，天之道也。
```

## 解释
**持而盈之，不若其已。**
手里端着个装满水的盆，你还要加水，那肯定得洒出来。不如差不多就得了，适可而止。

**揣而锐之，不可长保。**
把刀磨得太快，刀刃就薄了，用两下就崩了。这叫过犹不及。

**金玉满堂，莫之能守。**
钱再多你也守不住，富贵了就狂得不行，那是自己在找麻烦。

**功遂身退，天之道也。**
事情办成了，名利也有了，这时候要懂得让位、低调。这是老天爷的规矩。

## 分析
【现实逻辑】
老子这章讲的是“度”。这个世界是有平衡的，你占得太多，必然会招人怨；你表现得太狂，必然会招人打。就像月亮，圆了之后就开始缺，这是谁也改变不了的自然规律。

【案例拆解】
看看历史上那些功臣，凡是懂得“功遂身退”的，比如范蠡、张良，最后都得了善终。而那些舍不得权力、富贵了就嚣张的，大多没好下场。现在的商界也一样，很多大佬在最红火的时候选择退休或去做公益，那是真聪明，他们保住了已经得到的，避开了接下来的坑。

【生活智慧】
做人别太“满”。说话留三分，赚钱留三分，显摆也留三分。别把自己磨得太尖锐，那样容易折断。尤其是在顺风顺水的时候，一定要记得收敛。富而不骄，贵而不溢，这才是长久富贵的秘诀。
