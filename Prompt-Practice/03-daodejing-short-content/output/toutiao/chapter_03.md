# 第 3 章：虚其心，实其腹 | 好的管理，不应该让员工互相“卷”
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
不上贤，使民不争；
不贵难得之货，使民不为盗；
不见可欲，使民心不乱。
是以圣人之治，虚其心，实其腹，弱其志，强其骨。
常使民无知无欲，使夫智者不敢为也。
为无为，则无不治。
```

## 解释
**不上贤，使民不争。**
不刻意拔高某些人的名声，就不会诱发大家的攀比和争斗。很多所谓的“贤人”不过是虚名，反而带坏了社会风气。

**不贵难得之货，使民不为盗。**
不要过度炒作奢侈品和稀缺物资，大家心平气和地生活，自然也就没有了抢夺和偷盗。

**是以圣人之治，虚其心，实其腹。**
好的管理是让大家少点弯弯绕绕的心眼（虚其心），生活有保障，吃得饱穿得暖（实其腹），身体强健，心态端正。

**为无为，则无不治。**
领导者以身作则放下私欲，顺其自然，整个团队自然和谐高效。

## 分析
【现实逻辑】
老子这章常被误解为“愚民”，其实他是在讲“去伪存真”。现在的社会，到处都在制造焦虑：名校名企、黄金钻石。这些“可欲”的事物点燃了人们的贪婪，让人变得暴躁、扭曲。

【案例拆解】
看那些优秀的技术驱动型公司，他们往往不搞末位淘汰，也不鼓励996。相反，他们给员工提供极其优厚的福利和自由的氛围。这就是“实其腹、强其骨”。在这种宽松的环境下，员工反而能爆发惊人的创造力。这就是“为无为，则无不治”。

【生活智慧】
人活着，五谷杂粮、粗布长衫足矣。与其花时间去追逐那些被炒作出来的“难得之货”，不如多读几本书，充实精神世界。少一点智巧伪诈，多一点坦诚实在。
