# 第 2 章：有无相生，难易相成 | 顺应规律才是最高级的管理
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天下皆知美之为美，斯恶（wù）已；
皆知善之为善，斯不善已。
故有无相生，难易相成，
长短相较，高下相倾，
音声相和（hè），前后相随。
是以圣人处无为之事，行不言之教。
万物作焉而不辞，生而不有，为而不恃，功成而弗居。
夫唯弗居，是以不去。
```

## 解释
**天下皆知美之为美，斯恶已。**
大家都在追求美的时候，丑的概念就显现了。事物都有对立面，没有绝对的好，也没有绝对的坏，都是比较出来的。

**故有无相生，难易相成，长短相较，高下相倾。**
有和无相互转化，难和易相互形成，长短、高下、前后都是相互依存的。这是世间万物运行的基本法则。

**是以圣人处无为之事，行不言之教。**
聪明的管理者懂得“无为”，不过度干预，用实际行动而不是空头支票来引导大家。

**功成而弗居，夫唯弗居，是以不去。**
事情做成了，不把功劳全算在自己头上。正因为不贪功、不傲慢，你的成就和威信反而能长久保存，没人能抢走。

## 分析
【现实案例】
为什么很多家长越管孩子，孩子越叛逆？为什么很多老板越强调绩效，员工越想摸鱼？老子在2000年前就给出了答案：因为你破坏了“自然规律”。你越是刻意追求某个结果，往往越会催生它的反面。

【管理智慧】
真正的“圣人”管理，是提供环境让万物“自作”。在企业里，这叫充分授权和信任。不要按个人的偏好去揠苗助长，要顺应事物的本心。当你做到了“为而不恃”，也就是做了实事但不显摆，下属反而会打心底里佩服你。

【心态调整】
人到中年，要学会看淡那些所谓的“高下”和“长短”。时代成就了我们，而不是我们成就了时代。明白“功成弗居”的道理，在顺境时保持清醒，在逆境时懂得转化。不争，故天下莫能与之争。
