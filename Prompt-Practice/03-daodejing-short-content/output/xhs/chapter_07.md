# 第 7 章：天长地久 | 顶级玩家的潜规则：无私而成其私 ♾️
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天长，地久。
天地之所以能长且久者，以其不自生也，故能长生。
是以圣人后其身而身先，外其身而身存。
非以其无私邪（yé）？故能成其私。
```

## 解释
**天长，地久。天地之所以能长且久者，以其不自生也，故能长生。**
天地恒久存在。天地之所以能长久，是因为它们不为了自己的私利而生存运行，所以才能长生不老。

**是以圣人后其身而身先，外其身而身存。**
因此，高明的圣人遇事总是谦让在后，结果反而能赢得众人的拥护而领先；他把自己的安危置之度外，结果反而能保全自己的生命。

**非以其无私邪？故能成其私。**
这不正是因为他的无私吗？正因为无私，结果反而成就了他的自我。

## 分析
💡 **核心逻辑：** 这是一个极其高级的生存策略。天地不为自己活，所以万物都离不开它；圣人不为自己争，所以大家都愿意推举他。老子告诉我们，当你放下了对“小我”利益的执着，转而去成就“大我”或他人的利益时，你最终获得的私利反而更多。

💼 **职场痛点：** 现在的职场有很多“精致利己主义者”，凡事抢功劳，遇事推责任。短期看似乎占了便宜，但长期看，这种人路越走越窄。真正的顶级管理者深谙“后其身”的道理：让利给团队，身先士卒。当你成就了下属，下属自然会把你抬到更高的位置。这就是“身先”和“身存”的逻辑。

🌱 **行动建议：** 尝试“利他主义”的思维。在团队合作中，先考虑如何让项目成功，而不是先考虑如何表现自己。当你真正做到“外其身”，不被眼前的蝇头小利困扰时，你的格局和声望自然会建立。记住，最持久的成功，往往是利他之后顺带的结果。
