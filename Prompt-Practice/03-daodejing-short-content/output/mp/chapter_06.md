# 第 6 章：玄牝之门，是谓天地根
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
谷神不死，是谓玄牝（pìn）。
玄牝之门，是谓天地根。
绵绵若存，用之不勤。
```

## 解释
**谷神不死，是谓玄牝。**
“道”就像山谷中那永恒不灭的生机，空虚而灵动，它被称作玄妙的母性本源。

**玄牝之门，是谓天地根。**
这个玄妙母体的产门，是天地万物产生的总根源。万物皆由此出，生生不息。

**绵绵若存，用之不勤。**
它若隐若现地持续存在，它的能量无穷无尽，供人取用却永不疲劳、永不衰竭。

## 分析
**深度洞察：**
老子在本章以极其形象的语言赞美了“道”的创造力。通过“谷”和“牝”的意象，他揭示了一个深刻的哲学命题：虚空是孕育实体的基础，柔弱是生发刚强的母体。这是一种“上善”的生机，它不主宰，只孕育；不占有，只奉献。

**时代关联：**
在我们的传统认知中，往往过度推崇扩张、征服等“父性”力量。然而，在环境复杂、资源受限的今天，那种具备承载力、包容力和持续性的“母性智慧”显得尤为珍贵。无论是家庭关系的维系，还是生态环境的保护，都需要我们回归“天地根”，去学习那种绵延不绝、润物无声的处世态度。

**实践建议：**
建立你的“蓄水池”意识。在事业和学习中，不要总是追求瞬间的爆发，而要追求“绵绵若存”的持续性。保持内心的“虚”（谷），才能不断吸收新知；保持心态的“柔”（牝），才能在面对挫折时具备极强的韧性。当你不再焦虑于即时的回报（用之不勤），你反而能掌握那份最持久的创造力。
