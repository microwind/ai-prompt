# 第 2 章：有无相生，难易相成
> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天下皆知美之为美，斯恶（wù）已；
皆知善之为善，斯不善已。
故有无相生，难易相成，
长短相较，高下相倾，
音声相和（hè），前后相随。
是以圣人处无为之事，行不言之教。
万物作焉而不辞，生而不有，为而不恃，功成而弗居。
夫唯弗居，是以不去。
```

## 解释
**天下皆知美之为美，斯恶已；皆知善之为善，斯不善已。**
天下人都知道什么是美，也就有了丑的概念；都知道什么是善，也就有了恶的界定。美的产生，同时也定义了丑，两者是相辅相成的。

**故有无相生，难易相成，长短相较，高下相倾。**
“有”和“无”相互转化，“难”和“易”互为前提，“长”和“短”互为对比，“高”和“下”互为倚靠。世间万事万物都遵循这种互补与平衡的法则。

**是以圣人处无为之事，行不言之教。**
因此，圣人用“无为”的胸怀去应对世事，不乱作为；用身教代替说教，顺应事物的本性去引导。

**生而不有，为而不恃，功成而弗居。夫唯弗居，是以不去。**
孕育万物而不占为己有，成就事业而不自命不凡，大功告成而不自居其功。正因为他不贪恋权位与名利，所以他的功绩和名望反而能长存人心。

## 分析
**深度洞察：**
老子揭示了一个永恒的真理：万物皆在关系中定义。我们对世界的认知往往陷入“二元对立”的误区，非黑即白。然而，真正的智慧是看到对立面之间的统一。没有丑的衬托，美便失去了意义；没有难的磨砺，易也无从谈起。

**社会关联：**
现代社会的内卷，本质上是过度追求“长短相较”和“高下相倾”。当所有人都在争夺那个名为“美”或“成功”的标签时，社会整体的焦虑感便随之爆棚。老子提倡的“无为”，并非无所作为，而是反对“揠苗助长”式的盲动。在教育、职场和人生规划中，顺应本心和客观规律，往往能达到“事半功倍”的效果。

**实践建议：**
学会“利他”即是“利己”。当你能做到“生而不有、为而不恃”时，你其实是在建立一种极其深厚的个人信用。不居功自傲，会让你拥有更和谐的人际关系和更广阔的合作空间。在取得成绩时，归功于时代和团队，这种大格局不仅是修养，更是保全事业长久的不二法门。
