# 🧩 股市点评 Skill 生成文档

> 用于将前面的需求文档、内容设计文档和生产计划文档，进一步整理为可复用的股市点评 skill 生成输入

---

## 📌 目标

基于前面 3 份文档，生成一个适合反复调用的股市点评 skill。这个 skill 的目标不是预测市场，而是在固定时段基于输入数据生成结构稳定、语言克制、信息完整的市场点评内容。

---

## 🎯 Skill 定位

建议将 skill 定位为：

- **类型**：财经内容生成 skill
- **适用市场**：A 股
- **适用时段**：
  - 早盘开盘 30 分钟内
  - 午盘收盘后
  - 收盘后
- **核心能力**：
  - 读取结构化行情输入
  - 识别指数、情绪、热点、成交与资金变化
  - 按时段输出对应点评
  - 自动附带风险边界和观察点

---

## 🧱 推荐 Skill 结构

建议 skill 至少包含以下部分：

1. **Skill 名称**
   - `a-share-market-commentary`

2. **Skill 描述**
   - 用于根据 A 股实时或阶段性盘面数据，生成早盘、午盘、收盘点评内容

3. **输入字段**
   - `session_type`
     - 可选值：`morning_open_30m` / `midday_close` / `market_close`
   - `trade_date`
   - `index_summary`
   - `turnover`
   - `advancers_decliners`
   - `hot_sectors`
   - `weak_sectors`
   - `leading_stocks`
   - `capital_flow`
   - `market_sentiment`
   - `extra_notes`

4. **输出字段**
   - `title`
   - `summary`
   - `body`
   - `watch_points`
   - `risk_notice`

5. **固定规则**
   - 不输出买卖建议
   - 不承诺涨跌判断
   - 不夸大市场情绪
   - 以输入数据为依据，不编造事实
