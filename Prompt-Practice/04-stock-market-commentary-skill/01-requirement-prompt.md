# 🧾 股市点评提示词需求文档

> 用于让模型输出一份完整、可落地、可继续进入内容设计和 skill 设计阶段的需求分析文档

---

## 📌 适用场景

当你要建立一套每天可重复使用的股市点评 Prompt，希望 AI 先帮你完成点评目标、输入数据范围、输出边界、时段差异、风险约束整理时，可以使用本提示词。

---

## 🎯 Prompt 目标

让模型输出：

- 点评项目目标
- 三个时段的内容定位
- 输入数据需求
- 输出结构需求
- 风格与合规要求
- 风险、假设和待确认问题

---

## ✅ 完整 Prompt 模板

```markdown
你是一位资深财经内容策划兼 A 股盘面分析编辑，擅长将实时行情信息整理成结构化、清晰、克制的市场点评内容。

我准备建立一套“每日股市点评 Prompt 与 skill”，用于在每个交易日的以下 3 个时间点生成市场点评：
1. 早盘开盘 30 分钟内
2. 午盘收盘后
3. 下午收盘后

请你基于下面的信息，输出一份完整的需求分析文档。

【项目背景】
我希望基于真实、可靠、公开可获取的 A 股行情数据和盘面信息，生成日更股市点评内容。后续我会基于你的输出继续做内容设计、执行计划以及 skill 生成。

【已知需求】
1. 每天需要固定生成 3 类点评：
   - 早盘点评
   - 午盘点评
   - 收盘点评
2. 输出要能反映：
   - 指数表现
   - 市场情绪
   - 热点板块
   - 成交情况
   - 领涨领跌结构
   - 资金动向
3. 数据来源要求：
   - 来自真实、可靠、公开可获取的数据
   - 必须强调数据可信性、时效性和合规性
4. 内容要求：
   - 简洁
   - 有结构
   - 适合日更输出
   - 不带投资建议性质

【你的任务】
请不要直接生成点评正文，而是先把需求分析清楚。你需要站在财经内容策划和盘面信息整理的视角，补全我当前需求里缺失但必须明确的内容。

【分析要求】
1. 明确项目目标和内容价值
2. 明确目标读者和使用场景
3. 区分 3 个时段点评的功能定位
4. 拆解每类点评应包含的核心信息模块
5. 明确输入数据类型、字段建议和优先级
6. 明确输出结构和篇幅边界
7. 明确语言风格、风险提示和合规边界
8. 明确哪些内容必须避免，例如喊单、绝对判断、夸张表述
9. 明确后续做成 skill 时需要固定的输入输出格式
10. 明确风险点、依赖项和待确认问题

【特别约束】
1. 输出内容必须贴合 A 股日内点评场景
2. 不要编造不可获得的数据源
3. 涉及实时数据时，要提醒交易时段、延迟、数据刷新差异和合规使用限制
4. 不要输出投资建议导向内容，系统定位应为“市场观察与盘面整理工具”
5. 输出要适合继续作为后续内容设计、生产计划和 skill 生成的输入材料

【输出格式】
请严格按以下结构输出：

# 项目需求分析

## 1. 项目目标

## 2. 内容价值

## 3. 目标读者与使用场景

## 4. 三类点评的功能定位
- 早盘点评
- 午盘点评
- 收盘点评

## 5. 核心信息需求
- 指数信息
- 成交信息
- 涨跌结构
- 板块题材
- 资金动向
- 重点个股

## 6. 输入数据需求与来源约束
- 数据类型
- 推荐来源类别
- 更新频率建议
- 可信性校验建议
- 合规注意事项

## 7. 输出结构需求
- 标题
- 正文结构
- 结尾观察点
- 风险提示

## 8. 风格与边界要求

## 9. Skill 化建议
- 固定输入字段
- 固定输出字段
- 适配场景

## 10. 风险与依赖

## 11. 待确认问题清单

## 12. 建议的优先级
- P0
- P1
- P2

请使用专业、清晰、可落地的中文输出。
```

---

## 💡 使用建议

- 第一次先让模型输出完整需求分析
- 第二轮可继续补充你的主发布渠道、读者类型、篇幅偏好
- 如果后面要生成 skill，建议保留“输入数据需求与来源约束”“输出结构需求”“Skill 化建议”

---

## 🧪 推荐补充参数

如果你后续掌握了更多信息，可以把下面参数补进去：

- 主发布渠道：公众号 / 小红书 / 微博 / 知乎
- 读者类型：普通投资者 / 财经内容读者 / 短线观察用户
- 风格偏好：资讯型 / 点评型 / 复盘型
- 每篇字数上限
- 是否保留“次日观察点”
