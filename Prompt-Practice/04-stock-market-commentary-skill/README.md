# 📊 股市点评提示词与 Skill 实战教程

> 以“每天在早盘开盘 30 分钟内、午盘收盘后、下午收盘后生成股市点评内容”为例，整理一套可直接用于生成 Prompt 与 skill 的实战文档

---

## 📌 项目背景

目标是建立一套可复用的股市点评 Prompt 与 skill，用于在 A 股交易日的 3 个固定时段，基于真实行情数据和盘面信息，快速生成结构清晰、口径统一、适合内容发布的股市点评文本。

这次实战的重点不是直接输出当天点评内容，而是先沉淀 9 份文档，作为后续生成 Prompt、组装 skill、批量执行日更点评流程的基础输入。

## 🧭 本次实战过程记录

### 第1步：明确内容目标

先把原始需求还原成明确目标：

- 每个交易日输出 3 次股市点评
- 时间点分别为：
  - 开盘后 30 分钟内
  - 午盘收盘后
  - 下午收盘后
- 内容应基于真实、可靠、公开可获取的行情和盘面数据
- 输出不是投资建议，而是市场观察与盘面总结

### 第2步：拆分点评场景

把需求拆成 3 个独立点评场景：

1. **早盘点评**
   - 关注开盘情绪
   - 关注指数强弱
   - 关注热点板块与领涨个股
   - 关注开盘 30 分钟内的资金偏好

2. **午盘点评**
   - 关注上午盘整体结构
   - 关注热点是否扩散或分化
   - 关注成交额、涨跌家数、板块轮动
   - 关注下午盘可能需要继续观察的点

3. **收盘点评**
   - 关注全天市场表现
   - 关注主线与分支题材
   - 关注北向资金、成交额、情绪强弱
   - 关注次日观察重点

### 第3步：拆分核心能力

为了让 Prompt 和 skill 更稳定，需要明确 4 组核心能力：

1. **行情输入标准化**
   - 指数
   - 成交额
   - 涨跌家数
   - 板块表现
   - 领涨领跌个股
   - 资金流向

2. **时段化点评逻辑**
   - 不同时段看点不同
   - 早盘强调开局与情绪
   - 午盘强调结构与延续性
   - 收盘强调总结与次日观察点

3. **内容风格统一**
   - 简洁
   - 清晰
   - 有结构
   - 不喊单
   - 不夸张

4. **Skill 化封装**
   - 固定输入字段
   - 固定输出结构
   - 固定风险提示
   - 方便后续每天重复调用

### 第4步：将项目拆成 4 类文档

为了方便后续直接生成和使用 skill，本次文档拆成 4 类：

1. **需求提示词**
   - 让模型澄清点评目标、输入范围、输出边界、风险约束

2. **内容设计提示词**
   - 让模型设计三类点评模板、结构、篇幅、口径和风格规范

3. **生产计划提示词**
   - 让模型设计日更执行流程、输入准备、质检和发布节奏

4. **Skill 生成文档**
   - 让模型基于前面成果生成可复用 skill 说明与调用方式

5. **最终可用 Prompt 集**
   - 直接提供早盘、午盘、收盘和通用 Prompt 成品

6. **Skill 模板**
   - 直接提供可复制改造的 `SKILL.md` 模板

7. **真实 Skill 目录**
   - 直接落一个可复用的 skill 文件夹，包含 `SKILL.md` 和示例输入

8. **每日数据录入模板**
   - 提供每天早盘、午盘、收盘可直接填写的字段模板

9. **日更操作手册**
   - 提供从填数据到生成点评再到人工复核的执行步骤

## 🧱 后续如何扩展

后续你还可以沿这条线扩展：

1. 增加“盘前预判”版本
2. 增加“周评/月评”版本
3. 增加“小红书版/公众号版/短视频口播版”多平台模板
4. 增加自动读取数据后的一键生成 skill

这样可以逐步把单次 Prompt，沉淀成稳定的日更点评工作流。
