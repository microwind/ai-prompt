# 🏗️ 股市点评提示词内容设计文档

> 用于让模型根据需求分析文档产出一份完整的点评模板、输出结构和 skill 设计方案

---

## 📌 适用场景

当你已经完成需求分析，希望 AI 继续输出三类点评模板、字段设计、篇幅规范、风格约束和 skill 输入输出结构时，可以使用本提示词。

---

## 🎯 Prompt 目标

让模型输出：

- 三类点评模板
- 每类点评的核心字段
- 固定输出结构
- 篇幅与风格规范
- skill 输入输出设计
- 质量校验标准

---

## ✅ 完整 Prompt 模板

```markdown
你是一位资深财经内容总编，同时熟悉 A 股盘面分析、日内复盘写作、结构化 Prompt 设计和 skill 封装。

现在我准备建立一套“每日股市点评 Prompt 与 skill”。下面我会提供需求分析结果，请你基于这些内容输出一份完整的内容设计方案。

【输入材料】
以下是已经确认的需求分析文档：

{在这里粘贴需求分析结果}

【你的任务】
请基于需求文档，设计一套可落地、可重复执行、适合做成 skill 的点评内容方案。重点关注早盘开盘 30 分钟内、午盘收盘后、下午收盘后 3 个时段的不同写法、结构和观察重点。

【设计要求】
1. 为以下 3 类点评分别设计模板：
   - 早盘点评
   - 午盘点评
   - 收盘点评
2. 每类点评都要说明：
   - 核心目标
   - 必备输入字段
   - 推荐输入字段
   - 输出结构
   - 适合的篇幅范围
3. 明确早盘、午盘、收盘各自应该关注的重点差异
4. 设计统一语言风格：
   - 克制
   - 清晰
   - 有结构
   - 不喊单
   - 不夸张
5. 设计 skill 需要的固定输入字段与固定输出字段
6. 给出一套可复用的通用 Prompt 模板，以及 3 套分时段 Prompt 模板
7. 给出质量校验标准，防止：
   - 数据堆砌没有结论
   - 语气过满
   - 偏离时段重点
   - 误导为投资建议
8. 给出适合后续自动化调用的结构化建议

【特别约束】
1. 必须以真实行情和盘面信息为输入前提
2. 不要输出任何承诺收益或明确买卖建议性质的话术
3. 不要把内容写成口号式喊盘文案
4. 要体现不同交易时段的信息密度差异
5. 输出要足够结构化，方便后续继续生成 skill

【输出格式】
请严格按以下结构输出：

# 内容设计方案

## 1. 设计目标与原则

## 2. 三类点评模板设计
### 2.1 早盘点评模板
### 2.2 午盘点评模板
### 2.3 收盘点评模板

## 3. 分时段差异化规则
- 早盘看什么
- 午盘看什么
- 收盘看什么

## 4. 通用输入字段设计
- 必填字段
- 选填字段
- 数据校验建议

## 5. 通用输出结构设计
- 标题
- 导语
- 核心点评正文
- 观察重点
- 风险提示

## 6. 通用 Prompt 模板

## 7. 三类分时段 Prompt 模板
- 早盘 Prompt
- 午盘 Prompt
- 收盘 Prompt

## 8. Skill 输入输出结构建议
- 输入 schema 建议
- 输出 schema 建议
- 调用场景建议

## 9. 质量校验标准
- 内容准确性
- 时段匹配性
- 可读性
- 合规性

## 10. 风险点与备选方案

请使用专业、清晰、可执行的中文输出。
```

---

## 💡 使用建议

- 先把 `01-requirement-prompt.md` 的输出粘到输入材料里
- 如果你有固定数据源字段，也可以一起贴给模型
- 为了后面生成 skill，建议重点保留“通用 Prompt 模板”“三类分时段 Prompt 模板”“Skill 输入输出结构建议”

---

## 🧪 推荐追加信息

如你已有内容偏好，可补充如下信息：

- 单篇字数：150 / 300 / 500
- 输出平台：公众号 / 小红书 / 微博
- 是否需要标题
- 是否需要结尾“后续观察点”
- 是否需要更偏资讯还是更偏点评
