# 🏗️ 高考志愿填报系统系统设计提示词

> 用于让模型根据需求分析文档产出一份完整的系统设计方案

---

## 📌 适用场景

当你已经完成需求分析，希望 AI 继续输出系统架构、模块设计、数据流转、推荐逻辑、接口设计和前端展示方案时，可以使用本提示词。

---

## 🎯 Prompt 目标

让模型输出：

- 整体技术架构
- 业务模块划分
- 数据整合与推荐流程
- 数据模型设计建议
- API 设计建议
- PC/H5 前端页面结构建议
- 安全性、稳定性、扩展性设计

---

## ✅ 完整 Prompt 模板

```markdown
你是一位资深系统架构师，同时熟悉教育咨询类 Web 系统、推荐系统、数据中台设计、前后端分离架构和多端展示设计。

现在我准备开发一个“高考志愿填报辅助系统”。下面我会提供需求分析结果，请你基于这些内容输出一份完整的系统设计方案。

【输入材料】
以下是已经确认的需求分析文档：

{在这里粘贴需求分析结果}

【你的任务】
请基于需求文档，设计一个可落地、可扩展、适合中小团队分阶段实现的系统方案。重点关注用户信息采集、院校专业数据整合、志愿匹配逻辑、方案生成、结果可解释性，以及 PC/H5 统一访问体验。

【设计要求】
1. 设计整体系统架构，包含前端、后端、数据导入、推荐引擎、缓存、存储
2. 设计数据流：从外部招生与录取数据导入，到清洗、标准化、匹配、方案生成、展示的完整链路
3. 设计核心业务模块：
   - 学生信息采集模块
   - 院校与专业数据管理模块
   - 志愿匹配与推荐模块
   - 冲稳保方案生成模块
   - 结果对比与解释模块
   - 配置与监控模块
4. 针对省份、年份、批次、选科规则差异，给出数据标准化设计建议
5. 针对“冲、稳、保”分类给出规则引擎或评分模型设计建议
6. 设计接口层：
   - 用户信息提交接口
   - 推荐结果查询接口
   - 院校专业筛选接口
   - 历史数据查询接口
   - 系统配置与数据状态接口
7. 设计前端页面结构，兼顾 PC 与 H5
8. 明确性能、缓存、容错、监控与告警方案
9. 明确免责声明、风险提示、数据更新与人工复核提示设计

【技术约束】
1. 系统定位是志愿填报辅助 Web 系统，不是完全自动决策系统
2. 前端要兼容 PC 与 H5
3. 可以采用前后端分离架构
4. 数据必须以真实可靠公开数据为前提
5. 设计时必须考虑不同省份与年份规则差异
6. 需要体现“清晰可信、易理解”的产品体验

【输出要求】
1. 优先给出落地方案而不是泛泛原理介绍
2. 每个模块都说明职责、输入、输出、依赖
3. 对关键规则、关键表结构和推荐逻辑给出建议
4. 对高风险点给出备选方案
5. 输出内容要足够结构化，方便后续继续生成开发计划和 skill

【输出格式】
请严格按以下结构输出：

# 系统设计方案

## 1. 设计目标与原则

## 2. 总体架构设计
- 架构分层
- 核心组件
- 部署建议

## 3. 核心业务模块设计
### 3.1 学生信息采集模块
### 3.2 院校与专业数据管理模块
### 3.3 志愿匹配与推荐模块
### 3.4 冲稳保方案生成模块
### 3.5 前端展示模块
### 3.6 配置、监控与告警模块

## 4. 数据流与处理流程
- 数据导入
- 数据清洗与标准化
- 用户画像生成
- 推荐匹配
- 方案输出
- 前端展示

## 5. 关键业务规则设计
- 省份/批次/年份差异处理
- 选科规则匹配逻辑
- 冲稳保分类逻辑
- 院校与专业推荐排序逻辑
- 风险提示逻辑

## 6. 数据模型设计建议
- 主要实体
- 关键字段
- 表关系建议
- 历史数据表/规则表建议

## 7. API 设计建议
- 接口清单
- 请求参数
- 响应结构
- 错误处理

## 8. 前端页面与交互设计建议
- PC 页面结构
- H5 页面结构
- 表单、对比、结果页组件建议
- 响应式适配建议

## 9. 性能与稳定性设计
- 缓存策略
- 降级策略
- 容错策略
- 监控指标

## 10. 安全、免责声明与合规建议

## 11. 技术选型建议
- 前端
- 后端
- 存储
- 缓存
- 任务调度

## 12. 风险点与备选方案

请使用专业、清晰、偏工程落地的中文输出。
```

---

## 💡 使用建议

- 先把 `01-requirement-prompt.md` 产出的结果贴到 `{在这里粘贴需求分析结果}` 中
- 如果你已经预设技术栈、支持省份或数据源，也可以一起补充到输入里
- 为了后面生成 skill，建议保留“关键业务规则设计”“数据模型设计建议”“API 设计建议”这三块

---

## 🧪 推荐追加信息

如你已有部分技术决策，可补充如下信息提升设计质量：

- 前端：Vue / React / Next.js
- 后端：Java / Node.js / Python
- 数据库：MySQL / PostgreSQL
- 缓存：Redis
- 图表：ECharts / AntV
- 是否需要后台数据管理端
