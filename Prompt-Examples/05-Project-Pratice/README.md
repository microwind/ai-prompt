# 🚀 项目实战教程

> 记录从业务想法到 Prompt 文档，再到 skill 生成素材的完整实战过程

---

## 📚 本目录包含

- **[热门股票 Web 系统](01-hot-stock-web-system/)** - 以“实时热门股票分析与整理系统”为例，演示如何拆出需求提示词、系统设计提示词、开发计划提示词
- **[高考志愿填报系统](02-gaokao-volunteer-system/)** - 以“分数、兴趣、城市偏好驱动的志愿填报辅助系统”为例，演示如何拆出需求提示词、系统设计提示词、开发计划提示词
- **[道德经短内容改写](03-daodejing-short-content/)** - 以“逐章输出适合小红书、微头条、知乎的简洁版本”为例，演示如何拆出需求提示词、内容设计提示词、生产计划提示词
- **[股市点评提示词与 Skill](04-stock-market-commentary-skill/)** - 以“早盘、午盘、收盘三个固定时段生成股市点评内容”为例，演示如何拆出需求提示词、内容设计提示词、生产计划提示词和 skill 生成文档

---

## 🎯 适用方式

这个目录适合记录一类更完整的 Prompt 实战过程：

1. 从一个真实业务目标出发
2. 先整理需求边界和数据约束
3. 再产出系统设计 Prompt
4. 再产出开发计划 Prompt
5. 最后将这些文档作为后续生成 skill 的输入材料

---

后续你继续新增实战目录时，建议保持统一结构：

---

## 💡 使用建议

- 每个实战目录只聚焦一个明确项目目标
- Prompt 文档尽量直接可复制、可改参、可复用
- 输出格式要稳定，方便后续生成 skill 或工作流
- 明确数据来源、约束条件、异常边界，避免 Prompt 过于空泛
