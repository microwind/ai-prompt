# 🧾 《理解道德经》短内容改写需求提示词

> 用于让模型输出一份完整、可落地、可继续进入内容设计阶段的需求分析文档

---

## 📌 适用场景

当你要把《理解道德经》按章节改写成适合小红书、微头条、知乎发布的简洁版本，希望 AI 先帮你完成目标澄清、风格边界、平台差异、内容约束整理时，可以使用本提示词。

---

## 🎯 Prompt 目标

让模型输出：

- 项目目标
- 目标读者与使用场景
- 各平台内容风格差异
- 单章改写规则
- 篇幅、语气、表达边界
- 风险、假设和待确认问题

---

## ✅ 完整 Prompt 模板

```markdown
你是一位资深内容策划编辑，同时熟悉中国经典文本的现代化表达、短内容写作和多平台内容适配。

我准备将《理解道德经》按章节整理成简洁版内容，适合发布在小红书、微头条、知乎等平台。请你基于下面的信息，输出一份完整的需求分析文档。

【项目背景】
原稿位于：https://github.com/jarry/daodejing/tree/main/notes

原稿以章节形式组织，主要内容来自《理解道德经》，每章通常包含原文、译文、逐句解释、心得总结。我希望基于这些原稿，为每一章输出一个简洁版本，适合短内容平台发布。

【已知需求】
1. 每一章都要输出一个“简洁版”
2. 内容要尽量保留原意，但表达更现代、更好读
3. 输出要适合：
   - 小红书
   - 微头条
   - 知乎
4. 目标效果：
   - 简洁
   - 易懂
   - 有传播性
   - 有阅读完成度
5. 不希望内容变成：
   - 生硬翻译
   - 营销号鸡汤
   - 过度玄学化
   - 与原意偏离太远

【你的任务】
请不要直接输出章节正文，而是先把需求分析清楚。你需要站在内容策划和编辑设计的视角，补全当前需求中缺失但必须明确的内容。

【分析要求】
1. 明确项目目标和内容价值
2. 明确目标读者画像
3. 明确不同平台的内容风格差异
4. 拆解单章内容应该如何处理，例如：
   - 是否保留原句
   - 是否加入一句核心总结
   - 是否加入现代生活解释
5. 明确篇幅建议
6. 明确语言风格要求
7. 明确哪些表达应该避免
8. 明确“忠于原意”和“适合传播”之间的平衡原则
9. 明确批量生产时需要统一的规范
10. 明确风险点、依赖项和待确认问题

【特别约束】
1. 必须以原稿内容为基础，不可脱离原文随意发挥
2. 输出定位是“简洁版理解与表达”，不是学术注释，也不是心灵鸡汤
3. 要考虑不同平台对篇幅、节奏、语气的差异
4. 要保留《道德经》的思想味道，但避免艰涩和故作高深
5. 输出要适合继续作为后续内容设计和生产计划的输入材料

【输出格式】
请严格按以下结构输出：

# 项目需求分析

## 1. 项目目标

## 2. 内容价值

## 3. 目标读者与使用场景

## 4. 核心内容需求
- 单章输入
- 单章输出
- 改写目标
- 平台适配要求

## 5. 平台风格差异建议
- 小红书
- 微头条
- 知乎

## 6. 单章改写关键原则
- 保留什么
- 可压缩什么
- 可补充什么
- 禁止什么

## 7. 篇幅与语言风格建议

## 8. 批量生产统一规范

## 9. 风险与依赖

## 10. 待确认问题清单

## 11. 建议的优先级
- P0
- P1
- P2

请使用专业、清晰、可落地的中文输出。
```

---

## 💡 使用建议

- 第一次先让模型输出完整需求分析
- 第二轮可继续补充你偏好的风格，比如“更白话”“更克制”“更像当代随笔”
- 如果后面要生成 skill，建议保留“平台风格差异建议”“单章改写关键原则”“批量生产统一规范”

---

## 🧪 推荐补充参数

如果你后续掌握了更多信息，可以把下面参数补进去：

- 目标读者：传统文化初学者 / 年轻职场人 / 泛哲学读者
- 风格偏好：更白话 / 更文雅 / 更像短评
- 是否保留章名
- 是否保留原文引句
- 单篇字数上限
