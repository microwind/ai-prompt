# 第 15 章：夫唯不盈，故能蔽而新成

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
古之善为士者，微妙玄通，深不可识。
夫唯不可识，故强为之容。
豫兮，若冬涉川；犹兮，若畏四邻；
俨兮，其若客；涣兮，若冰之将释；
敦兮，其若朴；旷兮，其若谷；浑兮，其若浊。
孰能浊以止，静之徐清？孰能安以久，动之徐生？
保此道者不欲盈，夫唯不盈，故能敝而新成。
```

## 解释
**古之善为士者，微妙玄通，深不可识。夫唯不可识，故强为之容。**
古代善于行“道”的人，见解深奥精微，无法被常人所深入理解，只能勉强形容。

**豫兮，若冬涉川；犹兮，若畏四邻；俨兮，其若客；涣兮，若冰之将释。**
他审慎得如同严冬过河；警觉地如同防备邻国；庄重得如同去作客；舒展得如同冰雪消融。

**敦兮，其若朴；旷兮，其若谷；浑兮，其若浊。**
他淳朴得如同未经雕琢的璞玉；豁达得如同深幽的山谷；浑厚得如同滚滚的江河。

**孰能浊以止，静之徐清？孰能安以久，动之徐生？**
谁能在浑浊中安静下来，使其逐渐澄清？谁能在安宁中变动起来，使其显现生机？

**保此道者不欲盈，夫唯不盈，故能敝而新成。**
持有此道的人不会自满。正因为从不自满，所以能不断去旧迎新。

## 分析
本章总结了有道之人的特质：谨慎、庄重、质朴、豁达。最核心的思想在于最后四个字——“夫唯不盈”。

“月盈则亏，水满则溢”。人一旦自满，就无法装下新的思想和机会。保此道者，懂得在浑浊中守静，在安定中生机。

这种“不自满”是一种自然的生命力。真正的强大不是一成不变的完美，而是保持一点“缺憾”和“虚空”，从而能不断吐故纳新。只有做到不自满，人生才能像四季循环一样，持续获得生机与成长。
