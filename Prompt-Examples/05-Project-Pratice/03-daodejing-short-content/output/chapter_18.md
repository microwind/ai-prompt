# 第 18 章：大道废，有仁义

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
大道废，有仁义；
智慧出，有大伪；
六亲不和，有孝慈；
国家昏乱，有忠臣。
```

## 解释
**大道废，有仁义；智慧出，有大伪。**
自然纯朴的“道”被废弃了，才开始提倡仁义。智巧伪诈出现了，才产生了虚伪。

**六亲不和，有孝慈；国家昏乱，有忠臣。**
父子兄弟不和睦了，才需要强调孝慈。国家陷于混乱黑暗，才显现出所谓的忠臣。

## 分析
本章老子展示了其超越时代的洞察力。在老子看来，当人们开始大张旗鼓地提倡某种美德时，往往意味着这种美德的本质已经缺失了。

这就像中医讲的“治未病”。如果一个社会、一个家庭本就和谐健康，自然不需要额外的礼教去约束。

我们要解决的是根源上的“大道”，而不是在系统崩溃后用道德标签去打补丁。真正的健康状态是不需要刻意标榜的。只有人人守住本真，回归自然法则，那些纷乱的伪善才会消失。
