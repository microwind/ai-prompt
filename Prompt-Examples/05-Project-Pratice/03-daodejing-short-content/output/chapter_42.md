# 第 42 章：道生一，一生二，二生三

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
道生一，一生二，二生三，三生万物。
万物负阴而抱阳，冲气以为和。
人之所恶，惟孤、寡、不毂，而王公以为称。
故物或损之而益，或益之而损。
人之所教，我亦教之：
强梁者不得其死，吾当以为教父。
```

## 解释
**道生一，一生二，二生三，三生万物。**
大道生出浑然一体的原始状态，衍生出阴阳两气，阴阳交融产生万物的基础，最后生出大千世界。

**万物负阴而抱阳，冲气以为和。**
万物背负阴影而向往阳光，阴阳二气交融达到平衡和谐。

**故物或损之而益，或益之而损。**
一切事物，减损它反而使其获益，增加它反而使其受损。

**强梁者不得其死，吾当以为教父。**
强横霸道的人往往没有好下场，我把这句话当作教导的宗旨。

## 分析
本章指出了万物进化的路径，并再次强调了“用弱不用强”的规律。

“道生万物”的过程是一个从无到有、从简单到复杂的过程。老子告诫我们要看到事物的对立面：你越想增强它，它可能越衰弱。这种辩证思维能让我们避免狭隘和片面。

做人尤其是做领导，不可过于强横。保持柔弱与谦卑，在阴阳平衡中找准位置。只有这样，才能顺应自然的节奏，避免“强梁”带来的灾祸。
