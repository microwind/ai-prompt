# 第 78 章：天下莫柔弱于水

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天下莫柔弱于水，而攻坚强者莫之能胜，以其无以易之。
弱之胜强，柔之胜刚，天下莫不知，莫能行。
是以圣人云：受国之垢，是谓社稷主；受国不祥，是为天下王。
正言若反。
```

## 解释
**天下莫柔弱于水，而攻坚强者莫之能胜，以其无以易之。**
天下最柔弱的东西莫过于水，但攻坚克难的力量却没有能胜过水的，也没有什么能替代水的。

**弱之胜强，柔之胜刚，天下莫不知，莫能行。**
弱能胜强、柔能克刚，这个道理天下没有人不知道，但却极少有人能真正去践行。

**是以圣人云：受国之垢，是谓社稷主；受国不祥，是为天下王。**
因此圣人常说：能够承受国家的屈辱，才配做国家的主人；能够承担国家的灾难，才配做天下的君王。

**正言若反。**
这些正直、正面的话，听起来往往像是反话一样不入耳。

## 分析
本章老子通过赞美水，再次强调了“柔弱胜刚强”的道理。水不争功、遇物成形、始终居下，这种品性最接近于“道”。人人都想求强、求多，而事实却是弱能胜强、少能胜多。

更深刻的智慧在于领袖的责任感。老子指出，真正的领袖是那些在危机时刻站出来“背黑锅”、担重任的人。要想拥有相应的地位，就必须承担相应的职责。君王当以国为重，与国家荣辱与共。

“正言若反”揭示了真理的微妙。好话听起来往往不顺耳，深刻的逻辑往往反直觉。理解了这种平衡与转化的规律，我们就能在低位承载一切，成就无可替代的价值。
