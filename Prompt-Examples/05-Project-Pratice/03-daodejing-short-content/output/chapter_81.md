# 第 81 章：天之道，利而不害

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
信言不美，美言不信；
善者不辩，辩者不善；
知者不博，博者不知。
圣人不积。既以为人己愈有，既以与人己愈多。
天之道，利而不害；圣人之道，为而不争。
```

## 解释
**信言不美，美言不信；善者不辩，辩者不善。**
真实可信的话不一定漂亮，漂亮的话往往不可信。善良的人不巧言善辩，巧辩的人往往并不善良。

**知者不博，博者不知。**
真正得道的人不卖弄学问，卖弄学问的人并没有领悟真谛。

**圣人不积。既以为人己愈有，既以与人己愈多。**
圣人从不为自己囤积占有。他帮助别人越多，自己反而越充足；给予别人越多，自己反而越富有。

**天之道，利而不害；圣人之道，为而不争。**
上天的规律是利于万物而不加伤害；圣人的准则是努力作为而不与人争夺。

## 分析
这一章是全书的总结。老子通过“利而不害，为而不争”道出了大道的中心思想。

真实的智慧往往是质朴的。老子提倡一种“无我利他”的观点：当你尽心帮助他人时，社会变得和谐，你自己的内心也会更加充盈。这不是厚黑学，而是一种双赢的自然结果。

无论治国理政还是为人处世，老子的观点都震古烁今：有所作为，但绝不为了私利去争夺。当你能为别人着想，顺应天道去奉献时，你就拥有了莫大的善良。这就是《道德经》留给我们的最高生存智慧。
