# 第 10 章：载营魄抱一

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
载营魄抱一，能无离乎？
专气致柔，能如婴儿乎？
涤除玄览，能无疵乎？
爱民治国，能无为乎？
天门开阖，能为雌乎？
明白四达，能无知乎？
生之畜之，生而不有，为而不恃，长而不宰，是谓玄德。
```

## 解释
**载营魄抱一，能无离乎？专气致柔，能如婴儿乎？**
使精神和肉体合一，能不分离吗？聚集精气使其恬静，能像婴儿般自然吗？

**涤除玄览，能无疵乎？爱民治国，能无为乎？**
清除内心杂念使其澄澈，能像明镜般没有瑕疵吗？爱民治国，能遵循无为而治吗？

**天门开阖，能为雌乎？明白四达，能无知乎？**
感官呼吸、言谈举止，能像处子般静柔吗？通晓天下，能不玩弄权术智巧吗？

**生之畜之，生而不有，为而不恃，长而不宰，是谓玄德。**
生养万物而不占有，有所贡献而不自恃有功，引导万物而不去主宰，这就是最高深的“德”。

## 分析
本章是修身入道的门槛。老子提出了六个反思，核心在于要求我们保持身心和谐，回归婴儿般的纯真。

在浮躁的社会中，人们往往为了迅速致富而干预自然、背离规律，结果搞得身心疲惫、扭曲狂躁。真正的“德”，是无我利他，是“生而不有、长而不宰”。

这种博大的胸怀，像父母对待孩子一样全心付出但不求掌控。只有平复心态，清除心灵的污垢，我们才能在贪婪中找到和善，在浮躁中找到宁静。
