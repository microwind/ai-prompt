# 第 7 章：天长地久

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天长，地久。
天地之所以能长且久者，以其不自生也，故能长生。
是以圣人后其身而身先，外其身而身存。
非以其无私邪？故能成其私。
```

## 解释
**天长，地久。天地之所以能长且久者，以其不自生也，故能长生。**
天长地久，天地之所以能永久存在，是因为它们不为了自己的生存而运行，所以才能长久。

**是以圣人后其身而身先，外其身而身存。**
因此，圣人处处礼让，把自己放在后面，反而能赢得拥护而领先；将自己置之度外，反而能保全自身。

**非以其无私邪？故能成其私。**
这不正是因为他的无私吗？所以反而成就了他自己。

## 分析
本章透彻地分析了生命的意义与管理者的境界。天地的“长生”源于其大公无私。

在现实世界中，人往往自私自利，急于争先。但老子告诉我们，真正的强者懂得“财散人聚”的道理。谦让与利他，并不是放弃自我，而是将生命推广到灵魂的范畴。

圣人通过无私的行为，赢得了百姓的爱戴，从而与天地一样长生不灭。这种“以无私成其私”的智慧，值得每一位管理者铭记：利他，才是最高级的利己。
