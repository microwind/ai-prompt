# 第 28 章：知其雄，守其雌

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
知其雄，守其雌，为天下溪。
为天下溪，常德不离，复归于婴儿。
知其白，守其黑，为天下式。
为天下式，常德不忒，复归于无极。
知其荣，守其辱，为天下谷。
为天下谷，常德乃足，复归于朴。
朴散则为器，圣人用之，则为官长，故大制不割。
```

## 解释
**知其雄，守其雌，为天下溪。为天下溪，常德不离，复归于婴儿。**
深知什么是强劲，却安守柔弱，甘做天下的溪谷。能做天下的溪谷，永恒的德就不会离去，回归到婴儿般纯真的状态。

**知其白，守其黑，为天下式。为天下式，常德不忒，复归于无极。**
深知什么是明亮，却甘守暗昧，为天下做范式。能为天下做范式，德行就不会出错，回归到无穷的境界。

**知其荣，守其辱，为天下谷。为天下谷，常德乃足，复归于朴。**
深知什么是荣耀，却安守卑辱，甘做天下的川谷。能做天下的川谷，德行才会充足，回归到纯朴的本原。

**朴散则为器，圣人用之，则为官长，故大制不割。**
纯朴的“道”散开成就万物，圣人掌握了它，就能成为领导者。进入了“道”的状态，黑白荣辱浑然一体，无需分割。

## 分析
本章详细讲解了修道者应有的心态：虚怀若谷、抱朴守真。

人天生追求荣耀与强盛，但如果管理者沉迷于此，便会走向反面。老子主张“知荣守辱”，这是一种极其深刻的自我修养。在弱肉强食的竞争中，守住那份“朴”和“柔”，反而能获得真正的尊敬。

“朴散则为器”。真正的领导者，能将“道”的智慧融入日常。他不重名利，不计毁誉，始终保持婴儿般的纯净。只有这种浑然一体的格局，才能成就伟大的事业。
