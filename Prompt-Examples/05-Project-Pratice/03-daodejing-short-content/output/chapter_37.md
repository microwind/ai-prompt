# 第 37 章：道常无为而无不为

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
道常无为而无不为。
侯王若能守之，万物将自化。
化而欲作，吾将镇之以无名之朴。
镇之以无名之朴，夫将不欲。
不欲以静，天下将自正。
```

## 解释
**道常无为而无不为。侯王若能守之，万物将自化。**
“道”通常看起来无所作为，而实际上无所不为。领导者若能遵循它，万物自会按照规律生长。

**化而欲作，吾将镇之以无名之朴。**
万物在生长中产生贪欲时，我就用“道”的质朴去引导它回归本真。

**镇之以无名之朴，夫将不欲。不欲以静，天下将自正。**
回归质朴后，贪欲就会消失。没有了贪欲，内心平静，天下自然会回归正道。

## 分析
本章进一步强化了“无为而治”的理念。老子的治国根本在于“无为”，治民的根本在于“无欲”。

“无为”不是毫不作为，而是顺应自然，不乱作为。通过建立符合规律的机制，减少人为的干扰，给予万物自由发展的空间。

这种“朴”的状态，能让人在物质享受之外，获得精神的充实。无论是管理国家还是企业，少一点花活，多一点尊重，顺应客观规律办事，局面自然会变得和谐安宁。
