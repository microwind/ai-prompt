# 第 66 章：以其不争，天下莫能与之争

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
江海所以能为百谷王者，以其善下之，故能为百谷王。
是以圣人欲上民，以其言下之；欲先民，以其身后之。
是以处上而民不重，处前而民不害。
是以天下乐推而不厌。
以其不争，故天下莫能与之争。
```

## 解释
**江海所以能为百谷王者，以其善下之，故能为百谷王。**
江海之所以能汇聚百川，是因为它善于处在低下的地位。

**是以圣人欲上民，以其言下之；欲先民，以其身后之。**
因此，圣人想管理百姓，就在言语上表现谦卑；想领导百姓，就把自己的利益放在百姓之后。

**是以处上而民不重，处前而民不害。是以天下乐推而不厌。**
所以圣人虽居上位，百姓却不感到压力；虽处人前，百姓却不觉得妨碍。天下人都乐于拥戴他而不厌弃。

**以其不争，故天下莫能与之争。**
正因为他不与人争夺利益，所以天下没有人能和他相争。

## 分析
本章形象地阐述了领导者与被领导者的辩证关系。江海因“善下”而伟大。

真正的领袖应具备水一样的品性：先天下之忧而忧，后天下之乐而乐。这种“不争”不是佛系，而是不争私利、不抢功劳。当你把成全他人作为目标时，他人自然会推举你。

“将心比心”是管理的核心。当领导者不再高高在上作威作福，而是通过服务与谦逊凝聚力量，他便获得了一种无法被撼动的地位。这也是“无为而治”在人际关系中的最高体现。
