# 第 21 章：孔德之容，惟道是从

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
孔德之容，惟道是从。
道之为物，惟恍惟惚。
惚兮恍兮，其中有象；
恍兮惚兮，其中有物。
窈兮冥兮，其中有精；
其精甚真，其中有信。
自今及古，其名不去，以阅众甫。
吾何以知众甫之状哉？以此。
```

## 解释
**孔德之容，惟道是从。**
大德的形态和运作，完全是由“道”来决定的。

**道之为物，惟恍惟惚。惚兮恍兮，其中有象；恍兮惚兮，其中有物。**
“道”这个东西，似有若无，恍恍惚惚。在那种不可捉摸的状态中，却有着具体的形象；在那种混混沌沌的状态中，却有着真实的实体。

**窈兮冥兮，其中有精；其精甚真，其中有信。**
它是那样的深远暗昧，其中却包含着最微小的精质（基本粒子）；这种精质是极其真实的，并且是有规律、可信验的。

**自今及古，其名不去，以阅众甫。吾何以知众甫之状哉？以此。**
从古至今，“道”的规律从未消失，人们通过它来观察万事万物的初始。我怎么知道万物起源的状况呢？就是通过认识“道”得到的。

## 分析
本章进一步揭示了“道”与“德”的关系。“道”是本质和载体，“德”是表现和运作。老子认为，“道”虽然无影无形，但绝非凭空臆造，它是基于“精”（最微小的物质粒子）的真实存在。

两千多年前的老子通过观察，预言了世界是由基本粒子构成的，这种哲学洞察力令人惊叹。他告诉我们，“道”决定了万物的生长与运行，是我们认识世界本质的唯一钥匙。

要想真正搞明白“道”，不能只看表象，而要深入到“恍惚”背后的规律中去。这种追求本质的精神，是每一个求道者和管理者都应具备的素质。
