# 第 2 章：天下皆知美之为美

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天下皆知美之为美，斯恶已；
皆知善之为善，斯不善已。
故有无相生，难易相成，
长短相较，高下相倾，
音声相和，前后相随。
是以圣人处无为之事，行不言之教。
万物作焉而不辞，生而不有，为而不恃，功成而弗居。
夫唯弗居，是以不去。
```

## 解释
**天下皆知美之为美，斯恶已；皆知善之为善，斯不善已。**
天下人都知道美之所以为美，是因为有了丑的概念；都知道善之所以为善，是因为有了恶的概念。

**故有无相生，难易相成，长短相较，高下相倾，音声相和，前后相随。**
所以，有和无相互依存，难和易相互促成，长和短相互显现，高和下相互依靠，音与声相互调和，前和后相互跟从——这是永恒不变的规律。

**是以圣人处无为之事，行不言之教。**
因此，圣人以“无为”的态度来处理世事，用“不言”的方式来进行教化。

**万物作焉而不辞，生而不有，为而不恃，功成而弗居。夫唯弗居，是以不去。**
听任万物自然兴起而不去刻意干涉，生养了万物而不占为己有，有所作为而不自恃有功，取得了成就而不居功自傲。正因为他不贪恋功劳，这些成就反而会永久留在人们心中。

## 分析
本章包含着深刻的辩证思维。老子通过层层推进的排比告诉我们：事物的所有对立面都是相互统一、相辅相成的。美丑、善恶、难易、高下，这些概念无一不是在对比中产生。我们不应该厚此薄彼，而应该以平和、无差别的态度对待世间万物。

“无为”并不代表消极，而是一种遵循客观规律的智慧。无论教育孩子还是经营企业，最高明的管理是顺应事物本来的逻辑（顺木之本），而不是掺杂过多的个人偏好去“揠苗助长”。当我们持有这种心态时，反而能把事情做得更好。

在这个追逐名利的时代，人们往往容易在做出一点成绩后就居功自傲、争名夺利。老子提醒我们，所谓的成功，更多是顺应了时代、依循了规律后的结果，是“时代成就了人”，而非“人成就了时代”。

真正有智慧的人，懂得在功成名就时保持低调与谦卑。不夸耀、不占有，这种“弗居”的姿态，不仅能让人远离灾祸，更能让其精神与成就如天地般长久存在。
