# 第 32 章：知止可以不殆

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
道常无名，朴。
虽小，天下莫能臣。
侯王若能守之，万物将自宾。
天地相合，以降甘露，民莫之令而自均。
始制有名，名亦既有，夫亦将知止，知止可以不殆。
譬道之在天下，犹川谷之于江海。
```

## 解释
**道常无名，朴。虽小，天下莫能臣。**
“道”始终是无名无状的，它非常质朴。虽然它细微得隐不可见，但天下没有什么力量能支配它。

**侯王若能守之，万物将自宾。**
君王如果能遵循“道”的规律，万物自然会归从。

**天地相合，以降甘露，民莫之令而自均。**
天地之气相合，降下甘露，无需干涉也能自然均匀分布。

**始制有名，名亦既有，夫亦将知止，知止可以不殆。**
治理天下要建立体制名分，既然有了名分，也要懂得制约和适可而止。知道止步，就不会有危险。

**譬道之在天下，犹川谷之于江海。**
“道”存在于天下，就如同百川河谷流归江海一样自然。

## 分析
本章强调了“朴”的特质与“知止”的智慧。统治者若能保持质朴，百姓自会安居乐业。

“知止可以不殆”是生存的关键。无论行政司法还是个人欲望，如果不能适可而止，事无巨细都要干预，欲望无止境扩张，危险就近在咫尺。

我们要学习“道”的质朴与自然。无论身居何位，都要不忘初心，在纷繁复杂的关系中找准边界。只有懂得退让与克制，人生才能像汇入大海的溪流一样，顺遂而长久。
