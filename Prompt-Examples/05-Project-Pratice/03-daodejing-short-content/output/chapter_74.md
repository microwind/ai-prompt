# 第 74 章：代大匠斫，希有不伤其手

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
民不畏死，奈何以死惧之？
若使民常畏死，而为奇者，吾得执而杀之，孰敢？
常有司杀者杀，夫代司杀者杀，是谓代大匠斫。
夫代大匠斫者，希有不伤其手矣。
```

## 解释
**民不畏死，奈何以死惧之？**
百姓如果连死都不怕了，又怎么能用死亡来威胁他们呢？

**若使民常畏死，而为奇者，吾得执而杀之，孰敢？**
如果百姓怕死，把作恶的人抓来杀掉，还有谁敢乱来呢？（这其实是反问，意在说明严刑峻法无法根治问题。）

**常有司杀者杀，夫代司杀者杀，是谓代大匠斫。**
刑罚应由专门的机构去执行。如果管理者越俎代庖去执法，就像代替高明的木匠去砍木头。

**夫代大匠斫者，希有不伤其手矣。**
代替木匠去砍木头的人，很少有不伤到自己手的。

## 分析
本章提出了极其先进的治理理念：施仁政与各司其职。老子反对严刑峻法，主张通过教化让百姓安居乐业。

同时，老子洞察到了“制度独立”的重要性。统治者不应干扰法制程序的正常运转。这种“代大匠斫”的比喻，深刻说明了破坏规矩、越级指挥的危害。

国家和组织要长治久安，必须让专业机构做专业的事。管理者肆意破坏平衡，最终伤害的是自己的统治根基。尊重规律与分工，才是正道。
