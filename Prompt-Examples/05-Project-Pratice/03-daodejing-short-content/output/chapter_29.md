# 第 29 章：天下神器，不可为也

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
将欲取天下而为之，吾见其不得已。
天下神器，不可为也，不可执也。
为者败之，执者失之。
是以圣人无为，故无败，故无失。
夫物或行或随；或歔或吹；或强或羸；或载或隳。
是以圣人去甚、去奢、去泰。
```

## 解释
**将欲取天下而为之，吾见其不得已。天下神器，不可为也，不可执也。**
想要强力干预去治理天下，我看是行不通的。天下是神圣的，不可违背民意去强行统治和占有。

**为者败之，执者失之。是以圣人无为，故无败，故无失。**
强行妄为的会失败，执着占有的会失去。所以圣人施行无为之治，因而不会失败，也不会失去。

**夫物或行或随；或歔或吹；或强或羸；或载或隳。是以圣人去甚、去奢、去泰。**
人有的前行，有的后随；有的轻缓，有的急促；有的强壮，有的虚弱；有的安稳，有的危险。所以圣人要去掉极端的、奢侈的、过度的东西。

## 分析
本章继续深入探讨“无为而治”。老子告诫统治者：天下是百姓的天下，不是个人的私产。

由于每个人天性不同、形态各异，管理者绝不能用一把尺子强行衡量所有人。任何强力的干预、自以为是的执念，最终都会适得其反。企业管理和家庭教育亦是如此。

“去甚、去奢、去泰”。无论做人还是做事，都要保持简单朴素，去掉自私与贪婪。只有顺天应人、尊重差异，不忘初心，才能在“无为”中成就大治。
