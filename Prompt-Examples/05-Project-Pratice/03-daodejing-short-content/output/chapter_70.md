# 第 70 章：被褐怀玉

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
吾言甚易知，甚易行。
天下莫能知，莫能行。
言有宗，事有君。
夫唯无知，是以不我知。
知我者希，则我者贵。
是以圣人被褐而怀玉。
```

## 解释
**吾言甚易知，甚易行。天下莫能知，莫能行。**
我的话本来很容易理解，也很容易实行。可惜天下竟没有人能真正懂得，没有人能去践行。

**言有宗，事有君。夫唯无知，是以不我知。**
言论有主旨，行事有根据。正是因为人们不了解这些规律，所以才不理解我。

**知我者希，则我者贵。是以圣人被褐而怀玉。**
理解我的人很少，效法我的人难能可贵。圣人往往穿着粗布衣服，怀里却揣着美玉。

## 分析
本章表达了老子对世人不识真理的遗憾。

“大道”往往外表朴素，甚至看起来平淡无奇。人们追求浮华与快速的成功，却不愿深入探究事物背后的运行规律。老子的“无为”在急功近利者看来，是无用的空谈。

“被褐怀玉”是对智者的精准刻画。真正有修为的人，不屑于外表的包装。我们要学会看透表象，去识别那些质朴外壳下的真知灼见。懂的人虽少，但那份坚持本身就极具价值。
