# 第 53 章：大道甚夷，而人好径

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
使我介然有知，行于大道，唯施是畏。
大道甚夷，而人好径。
朝甚除，田甚芜，仓甚虚；
服文采，带利剑，厌饮食，财货有余。
是谓盗竽，非道也哉！
```

## 解释
**使我介然有知，行于大道，唯施是畏。**
假使我稍微明白点道理，就会走光明大道，而害怕走上邪路。

**大道甚夷，而人好径。**
大道明明很平坦，但常人却偏偏喜好钻小道、走捷径。

**朝甚除，田甚芜，仓甚虚。**
统治者穿华丽衣服，带锋利宝剑，吃精美大餐，聚敛了无数财富；而老百姓的田园却荒芜，仓库空虚。

**是谓盗竽，非道也哉！**
这简直是强盗头的行径，根本不是正道！

## 分析
本章对比了“大道”与“邪道”。老子抨击了那些好大喜功、奢侈浪费的统治者。

现实中，人们往往为了快点达成目标而寻找捷径，甚至不惜走上歪门邪道。但老子告诉我们，捷径往往是陷阱。

真正的领导者应以民为本。那种只顾自己享乐、不顾百姓死活的行为，与强盗无异。踏踏实实走正道，虽然看起来慢，但才是真正的稳健与长久。
