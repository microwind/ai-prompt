# 第 9 章：持而盈之

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
持而盈之，不若其已；
揣而锐之，不可长保。
金玉满堂，莫之能守；
富贵而骄，自遗其咎。
功遂身退，天之道也。
```

## 解释
**持而盈之，不若其已；揣而锐之，不可长保。**
端着盛满水的器皿还不停加水，不如适可而止；捶打得过于锋利的尖刃，很难长久保持。

**金玉满堂，莫之能守；富贵而骄，自遗其咎。**
金银财宝堆满屋子，是守不住的；富贵之后变得骄纵，是自取其祸。

**功遂身退，天之道也。**
功成名就之后，懂得适时退避，这才符合自然的规律。

## 分析
本章告诫我们要凡事有度，适可而止。物极必反是亘古不变的真理。

满招损，谦受益。做人若过于锋芒毕露，不给自己留余地，人生就缺乏弹性。在这个物欲横流的时代，很多人赚够了钱却不知道收手，结果“金玉满堂”反而成了负担和祸端。

大智慧的人懂得“功成身退”。这不是放弃奋斗，而是懂得顺应规律，富而不骄，敛其光芒。给他人留空间，也是给自己留退路。
