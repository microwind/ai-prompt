# 第 34 章：大道泛兮，其可左右

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
大道泛兮，其可左右。
万物恃之以生而不辞，功成而不名有。
衣养万物而不为主，常无欲，可名于小；
万物归焉而不为主，可名为大。
以其终不自为大，故能成其大。
```

## 解释
**大道泛兮，其可左右。**
大道广泛流行，无处不在，左右逢源。

**万物恃之以生而不辞，功成而不名有。**
万物依靠它生长，它从不推辞；成就了万物，它从不占有。

**衣养万物而不为主，常无欲，可名于小。**
它滋养万物却不求做主宰，始终没有私欲，看起来似乎很微小。

**万物归焉而不为主，可名为大。以其终不自为大，故能成其大。**
万物归附它，它却不自居主人，这可以称之为伟大。正因为它始终不自以为大，所以才成就了它的伟大。

## 分析
本章赞美了“道”的宽广与无私。它贡献巨大，却不显山露水；它成就万物，却不求回报。

这种“不自为大”的精神，是领导力的最高境界。真正的领袖应该成全团队，而不是主宰团队。当一个人不再急于证明自己的伟大时，他的这种谦卑与包容，反而会让他获得真正的尊崇。

我们应从中学习“成全”的智慧。在生活和工作中，默默耕耘，不计虚名。这种淡泊的姿态，反而能让我们在长久的积累中，成就一番伟大的事业。
