# 第 69 章：祸莫大于轻敌

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
用兵有言：吾不敢为主而为客，不敢进寸而退尺。
是谓行无行，攘无臂，执无兵，乃无敌。
祸莫大于轻敌，轻敌几丧吾宝。
故抗兵相加，哀者胜矣。
```

## 解释
**吾不敢为主而为客，不敢进寸而退尺。**
用兵的法则是：我不敢主动进攻，而宁愿被动防御；不敢冒进一寸，而宁愿退后一尺。

**是谓行无行，攘无臂，执无兵，乃无敌。**
这就叫作行军不见阵列，奋力不露手臂，手中不拿兵刃。这种出奇制胜、了然于胸的境界，才是无敌的。

**祸莫大于轻敌，轻敌几丧吾宝。故抗兵相加，哀者胜矣。**
最大的祸害莫过于轻敌，轻敌会让我丢掉“慈、俭、让”这三件法宝。所以当两军势均力敌时，悲愤正义的一方必胜。

## 分析
本章探讨了军事中的“以退为进”策略。老子认为，防御往往比进攻更具正义感和凝聚力。

“不敢寸进，反而退尺”是审时度势的智慧。主动侵略是非正义的，而守卫家园则能激发士兵的潜能。这就是“哀兵必胜”。

这种思想告诉我们，不论在何种竞争中，都不可骄傲狂妄。轻敌是走向灭亡的开始。只有保持警惕，坚守正义与慈悲，才能在势均力敌的较量中，立于不败之地。
