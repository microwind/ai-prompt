# 第 68 章：不争之德，用人之力

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
善为士者不武，
善战者不怒，
善胜敌者不与，
善用人者为之下。
是谓不争之德，是谓用人之力。
是谓配天古之极。
```

## 解释
**善为士者不武，善战者不怒。**
善于当将帅的人，不逞勇武；善于打仗的人，不轻易被激怒。

**善胜敌者不与，善用人者为之下。**
善于战胜敌人的人，不与敌人正面硬拼；善于用人的人，对人才保持谦下。

**是谓不争之德，是谓用人之力。**
这就叫作不争的美德，这就叫作利用他人的力量。这符合自古以来的自然法则。

## 分析
本章将“无为”思想运用在竞争与管理中。核心是控制情绪与尊重人才。

一个容易暴怒、爱显摆武力的统帅，往往会乱了方寸。真正的强者是深谋远虑、沉着冷静的。他不争一时的意气，而是通过“为之下”的方式赢得人心。

“得人心者得天下”。善于用人，就是要充分尊重与授权。这种“不争之德”能凝聚起巨大的群体力量。不论治国还是经商，不狂、不怒、不抢，才能功成事遂。
