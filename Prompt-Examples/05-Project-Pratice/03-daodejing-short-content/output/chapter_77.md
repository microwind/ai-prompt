# 第 77 章：天之道，损有余而补不足

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天之道，其犹张弓与？
高者抑下，下者举之，有余者损之，不足者补之。
天之道，损有余而补不足。
人之道，则不然，损不足以奉有余。
孰能有余以奉天下，唯有道者。
是以圣人为而不恃，功成而不处，其不欲见贤。 
```

## 解释
**天之道，其犹张弓与？高者抑下，下者举之，有余者损之，不足者补之。**
自然的规律，不是很像拉弓射箭吗？弦拉高了就压低一点，低了就抬高一点；拉得过满了就减少一点，拉得不足就增补一点。

**天之道，损有余而补不足。人之道，则不然，损不足以奉有余。**
上天的规律，是减损多余的来补充不足的，以此维持平衡。可是人间的法则却往往相反，是削减贫穷不足的，来奉献给富贵有余的。

**孰能有余以奉天下，唯有道者。**
那么，谁能把自己多余的财富拿出来贡献给天下呢？只有真正有道的领导者才能做到。

**是以圣人为而不恃，功成而不处，其不欲见贤。**
因此，得道的统治者有所作为而不自傲，有了成就而不居功，他并不想彰显自己的贤能与伟大。

## 分析
本章体现了老子的“平衡思想”。自然界之所以能长久运转，是因为它始终维持着一种动态的平衡。而人性中的自私与贪婪，往往在不断打破这种平衡，造成贫富不均与权利不平等。

“天道有常，人道无常”。老子告诫统治者要抑制自己的私欲，“损有余而补不足”，厚待百姓，让利于民，保持自身的质朴与清静。只有利益均衡，社会才能实现长治久安。

圣人成功后不居其功，正是效法天道的法则。真正的圣贤会减损自己的富余而补充给天下。领导者如果能懂得这种差别并修正自己的德行，使得“人道如天道”，那便是达到了极高的境界。
