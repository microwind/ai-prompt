# 第 5 章：天地不仁

> 《道德经》简单解说版，用简单朴素语言解说。

## 原文
```
天地不仁，以万物为刍狗；
圣人不仁，以百姓为刍狗。
天地之间，其犹橐龠乎？
虚而不屈，动而愈出。
多言数穷，不若守于中。
```

## 解释
**天地不仁，以万物为刍狗；圣人不仁，以百姓为刍狗。**
天地并没有人类那样的仁义偏私，看待万物如同祭祀用的草狗一样平等自然。圣人效法天地，也不带偏见地对待百姓，让他们各守本性，自作自息。

**天地之间，其犹橐龠乎？虚而不屈，动而愈出。**
天地之间，不正像一个巨大的风箱吗？内里空虚却不会穷尽，越是鼓动，排出的风量就越多。

**多言数穷，不若守于中。**
政令繁杂干预过多，反而会使局势陷入困顿，不如守住内心的虚静，保持中立。

## 分析
本章揭示了一个朴素而深刻的真理：万物平等。天地运行周而复始，不因人的喜悲而改变，这种“无悲无喜”才是自然的基本性格。

真正的圣人应抛弃人为设置的等级偏见，减少不必要的干预，还世界以自由和清宁。这与儒家强调的仁义礼教不同，老子认为世界终究是平的，过度的说教和干预往往会导致“势穷力屈”。

“守中”不仅是管理者的智慧，也是个人的处世良方。在动荡中保持内心的虚静，不偏不倚，顺应天道。理解了“万物同源、一切根本乃是虚无”的道理，我们才能在喧嚣的竞争中，找到自由畅快呼吸的空间。
