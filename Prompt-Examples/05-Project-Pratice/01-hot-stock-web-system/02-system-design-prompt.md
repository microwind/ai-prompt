# 🏗️ 热门股票 Web 系统系统设计提示词

> 用于让模型根据需求分析文档产出一份完整的系统设计方案

---

## 📌 适用场景

当你已经完成需求分析，希望 AI 继续输出系统架构、模块设计、数据流转、接口设计和前端展示方案时，可以使用本提示词。

---

## 🎯 Prompt 目标

让模型输出：

- 整体技术架构
- 业务模块划分
- 数据采集与处理流程
- 数据模型设计建议
- API 设计建议
- PC/H5 前端页面结构建议
- 安全性、稳定性、扩展性设计

---

## ✅ 完整 Prompt 模板

```markdown
你是一位资深系统架构师，同时熟悉金融行情类 Web 系统、数据中台设计、前后端分离架构和多端展示设计。

现在我准备开发一个“实时热门股票分析与整理”的 Web 系统。下面我会提供需求分析结果，请你基于这些内容输出一份完整的系统设计方案。

【输入材料】
以下是已经确认的需求分析文档：

{在这里粘贴需求分析结果}

【你的任务】
请基于需求文档，设计一个可落地、可扩展、适合中小团队分阶段实现的系统方案。重点关注实时行情采集、热门榜单计算、板块题材统计、数据可信性、以及 PC/H5 统一访问体验。

【设计要求】
1. 设计整体系统架构，包含前端、后端、数据采集、任务调度、缓存、存储
2. 设计数据流：从外部行情源采集，到清洗、计算、存储、展示的完整链路
3. 设计核心业务模块：
   - 分时段热门股票榜单模块
   - 热门板块与题材统计模块
   - 数据源接入与校验模块
   - 榜单展示与检索模块
   - 配置与监控模块
4. 针对“开盘、午盘、收盘”三个时段，给出任务调度与快照策略设计建议
5. 针对沪指、深成指、创业板三个市场范围，设计统一的数据模型与筛选逻辑
6. 给出板块、题材上涨/下跌比例的计算逻辑建议
7. 设计接口层：
   - 榜单查询接口
   - 板块题材热度接口
   - 数据源状态接口
   - 时间段切换接口
8. 设计前端页面结构，兼顾 PC 与 H5
9. 明确性能、缓存、降级、容错、监控与告警方案
10. 明确安全、合规和免责声明设计建议

【技术约束】
1. 系统定位是 Web 系统，不是桌面终端
2. 前端要兼容 PC 与 H5
3. 可以采用前后端分离架构
4. 数据必须以真实可靠公开数据为前提，不能假设私有证券专线
5. 设计时要考虑交易时段内的刷新频率与非交易时段的降频策略
6. 需要体现“美观大方”的金融看板式产品体验

【输出要求】
1. 优先给出方案而不是泛泛原理介绍
2. 每个模块都说明职责、输入、输出、依赖
3. 对关键指标和关键表结构给出建议
4. 对高风险点给出备选方案
5. 输出内容要足够结构化，方便后续继续生成开发计划和 skill

【输出格式】
请严格按以下结构输出：

# 系统设计方案

## 1. 设计目标与原则

## 2. 总体架构设计
- 架构分层
- 核心组件
- 部署建议

## 3. 核心业务模块设计
### 3.1 热门股票榜单模块
### 3.2 热门板块与题材模块
### 3.3 数据接入与校验模块
### 3.4 调度与快照模块
### 3.5 前端展示模块
### 3.6 配置、监控与告警模块

## 4. 数据流与处理流程
- 数据采集
- 数据清洗
- 数据聚合
- 数据存储
- 数据分发
- 前端展示

## 5. 关键业务规则设计
- 开盘/午盘/收盘定义
- 热门股票榜单计算逻辑
- 成交量 Top20 逻辑
- 成交额 Top20 逻辑
- 板块和题材涨跌统计逻辑

## 6. 数据模型设计建议
- 主要实体
- 关键字段
- 表关系建议
- 快照表/汇总表建议

## 7. API 设计建议
- 接口清单
- 请求参数
- 响应结构
- 错误处理

## 8. 前端页面与交互设计建议
- PC 页面结构
- H5 页面结构
- 图表与榜单组件建议
- 响应式适配建议

## 9. 性能与稳定性设计
- 缓存策略
- 降级策略
- 限流策略
- 容错策略
- 监控指标

## 10. 安全与合规建议

## 11. 技术选型建议
- 前端
- 后端
- 存储
- 缓存
- 调度

## 12. 风险点与备选方案

请使用专业、清晰、偏工程落地的中文输出。
```

## 💡 使用建议

- 先把 `01-requirement-prompt.md` 产出的结果贴到 `{在这里粘贴需求分析结果}` 中
- 如果你已经预设技术栈，也可以把技术栈直接补充到输入材料里
- 为了后面生成 skill，建议保留“关键业务规则设计”“数据模型设计建议”“API 设计建议”这三块

## 🧪 推荐追加信息

如你已有部分技术决策，可补充如下信息提升设计质量：

- 前端：Vue / React / Next.js
- 后端：Java / Node.js / Python
- 数据库：MySQL / PostgreSQL
- 缓存：Redis
- 图表：ECharts / AntV
- 部署方式：Docker / Kubernetes / 云服务器
